> 此项目出自于 [杨CC资源站](https://ycc77.cn) 网址：ycc77.cn

## 三、目录与命名规范

### 层级

只有两层：`一级分类 / 技能目录`。不设二级分类，避免空壳目录套娃。

### 命名

1. 一级分类用中文领域名，四个字以内，见名知意；
2. 技能目录用「中文名-范围后缀」格式，中划线分隔，后缀概括该技能覆盖的板块或数量的量词；
3. 目录名一律中文，不使用拼音缩写、不使用英文；
4. 一个技能就是一个完整技能包，内部不再拆分。覆盖范围写在名字后缀和目录内 `README.md` 里，不靠拆目录表达。

示例：

```text
国学占卜/综合占卜-七层卜术/     # 不拆成 命/卜/相 三个目录
国学占卜/梅花易数-四法十八类/   # 四法指起卦法，十八类指占断类目
```

### 技能目录内部结构

```text
<一级分类>/<技能名-范围后缀>/
├── SKILL.md        # 必需。技能主文件，含 name、description 等元信息
├── README.md       # 必需。面向人的详细说明：做什么、覆盖什么、怎么用、边界在哪
├── LICENSE         # 可选。与根目录授权不同时才需要
└── ...             # 脚本、规则库、原文库、模板等资源
```

必备两条：

1. `SKILL.md` 缺了视为技能未完成，不予入库；
2. `README.md` 必须写清四件事：技能用途、覆盖范围、调用方式、能力边界。

## 四、安装使用

克隆整个仓库：

```bash
git clone https://github.com/ycc77cn/skills.git
```

按需把技能目录复制到所用 AI 工具的技能目录：

| 工具 | 技能目录 |
| --- | --- |
| Trae | `~/.trae-cn/skills/` 或项目内 `.trae/skills/` |
| Claude Code | `~/.claude/skills/` 或项目内 `.claude/skills/` |

示例，取梅花易数：

```bash
cp -r "skills/国学占卜/梅花易数-四法十八类" ~/.trae-cn/skills/meihua-yishu
```

因为技能目录带中文名，复制时建议指定目标目录名，避免工具侧识别异常。

## 五、贡献与收录

新增技能时按以下顺序操作：

1. 确认技能包完整，`SKILL.md` 存在且 `description` 能准确触发；
2. 在一级分类下建「中文名-范围后缀」目录，整包放入，不拆内部结构；
3. 补齐该目录的 `README.md`，写清用途、范围、用法、边界；
4. 更新本文件的技能清单表；
5. 确认无第三方版权内容、无付费版内容混入。
