# 电子取证 `forensics/`

电子数据取证类技能集合，强调证据链完整与操作可复现。

## 子类

| 子类 | 目录 | 中文名 | 内容 |
| --- | --- | --- | --- |
| memory-forensics | `memory-forensics/` | 内存取证 | 内存镜像获取、进程与网络痕迹提取、时间线还原 |
| log-analysis | `log-analysis/` | 日志分析 | Windows 事件日志、Linux 系统日志、应用日志排查 |

## 说明

取证类技能默认遵循三条底线：先固定证据再分析、操作全程留痕、结论与原始数据可回溯。
