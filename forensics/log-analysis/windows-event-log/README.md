# Windows 操作日志检查 `windows-event-log/`

Windows 事件日志取证技能。

## 规划内容

| 日志通道 | 关注点 |
| --- | --- |
| Security | 登录成功／失败（4624／4625）、特权使用、账户变更、审计策略变更 |
| System | 服务启停、驱动加载、系统异常 |
| Application | 应用崩溃、异常调用 |
| PowerShell | 脚本块日志（4104）、命令执行记录 |
| TaskScheduler | 计划任务创建与执行 |
| RDP | 远程登录会话、来源地址 |
