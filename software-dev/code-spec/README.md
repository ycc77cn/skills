# 代码规范 `code-spec/`

代码规范化技能，支持重构与生成两种模式，覆盖六个维度。

## 技能清单

| 技能 | 目录 | 状态 | 说明 |
| --- | --- | --- | --- |
| 代码编写与重构规范 | `code-refactor-spec/` | 待迁入 | 六维规范＋检查清单＋报告模板 |

## 六个维度

| 维度 | 覆盖内容 |
| --- | --- |
| 代码本体 | 结构、函数粒度、错误处理、复杂度 |
| 文件目录 | 分层、模块边界、命名一致 |
| 注释 | 中文注释、必要性与信息密度 |
| 接口命名 | 命名风格统一、语义明确 |
| 工程规范 | 依赖管理、配置外置、构建脚本 |
| 安全防护 | 输入校验、敏感信息、权限边界 |
