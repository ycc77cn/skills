## 分类原则

1. 一个技能包整体入库，不按术数门类拆成多个目录。门类归属写在技能名后缀与该技能的 `README.md` 里。
2. 技能名后缀要能自解释，看到 `七层卜术` 就知道这个包覆盖七层，不用点进去猜。
3. 古法讲「相由心生，命由己造」。本分类技能只做形格与规则的对应推演，不做吉凶断言，不替代现实判断。
