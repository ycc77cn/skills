# 梅花易数 全技能（meihua-yishu）

四法起卦、十八类占断的梅花易数技能，四阶段交互流程，输出含卦象图的 HTML 与 Markdown 双格式报告。

## 用途

接收求测请求后，先展示占断方向、引导补齐信息，再按用户选定的方法起卦，完成体用分析、卦气旺衰、互变错综推演，最后同时产出 HTML 与 Markdown 两份报告，并把结论讲给用户听。

## 覆盖范围

### 四种起卦法

| 起卦法 | 输入 | 说明 |
| --- | --- | --- |
| 时间起卦 | 年月日时 | 以农历年月日数加时辰数起上下卦与动爻 |
| 数字起卦 | 一至三组数字 | 按数字取卦，可加时辰定动爻 |
| 文字起卦 | 字或词 | 按字数、笔画、平仄取象 |
| 外应起卦 | 现场见闻转述 | 按物象、声象成卦 |

### 十八类占断

涵盖天时、人事、感情、事业、财运、健康、出行、失物、诉讼、考试、合作、家宅等方向，每类配独立判断规则。

### 推演规则

本卦、互卦、变卦三层推演，体用确定，应期推算，四时旺衰配五行生克。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型触发语句：算卦、占卜、起卦、问卦、测事、梅花易数。

执行顺序固定为四阶段：展示方向与引导提问 → 选择起卦法 → 执行起卦计算（含验证清单）→ 生成双格式报告并说明文档内容。

## 能力边界

1. 一事一占，混提多问要求拆分；
2. 起卦所需信息不全时回问补齐，不脑补干支与时间；
3. 结论仅供参考，明确标注以现实理性判断为准；
4. 不占生死寿夭、他人隐私与非法之事。
