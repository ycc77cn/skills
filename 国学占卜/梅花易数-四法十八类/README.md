# 梅花易数-四法十八类

梅花易数起卦与占断技能，支持四种起卦法，输出含卦象图的 HTML 与 Markdown 双格式报告。

## 用途

按用户提供的条件起卦，完成体用分析、卦气旺衰、互变错综推演，给出应期与行动建议，同时说明不确定处，不做吉凶绝对断言。

## 覆盖范围

### 四种起卦法

| 起卦法 | 输入 | 说明 |
| --- | --- | --- |
| 时间起卦 | 具体年月日时 | 以农历年月日数加时辰数起上下卦与动爻 |
| 数字起卦 | 一至三组数字 | 按数字取卦，可加时辰定动爻 |
| 文字起卦 | 字或词 | 按字数、笔画、平仄取象 |
| 外应起卦 | 见闻外应转述 | 按现场物象、声象成卦 |

### 十八类占断

感情、事业、财运、健康、出行、诉讼、寻物、考试、合作、家宅、婚姻、求人、失物、官非、搬迁、疾病、天气、其他综合。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型触发语句：算卦、占卜、起卦、问卦、测事、梅花易数。

输出为 HTML 报告与 Markdown 报告双格式，HTML 内嵌卦象图。

## 能力边界

1. 一事一占，混提多问要求拆分；
2. 起卦所需信息不全时回问补齐，不脑补；
3. 结论仅供参考，明确标注以现实理性判断为准。
