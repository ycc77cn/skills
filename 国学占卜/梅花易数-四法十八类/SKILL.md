# 梅花易数算卦 Skill

> 本 Skill 实现完整的梅花易数算卦流程：支持 AI 实际能执行的 4 种起卦方法（时间起卦/数字起卦/文字起卦/外应转述起卦），覆盖 18 类占断方向（感情/事业/财运/健康/失物等），采用四阶段交互流程，同时输出 HTML 和 Markdown 两种格式报告。

---

## 一、交互流程设计（四阶段）

### 阶段1 — 展示方向 + 引导提问

当用户表达算卦意图后，首先展示问卦方向菜单，分四大类：

|------|---------|-------------|
| 感情类 | 男问女感情、女问男感情、婚姻现状 | 婚姻占(5) |
| 事业类 | 事业发展、求名求谋、官司诉讼 | 求名占(9)+求谋占(8)、官讼占(17) |

| 生活类 | 健康疾病、出行平安、行人归期、失物寻找、其他 | 疾病占(16)、出行占(12)、行人占(13)、失物占(15)、其余 |

### 阶段2 — 选择起卦方法

展示 AI 实际能执行的 4 种起卦方法：

| 选项 | 方法 | AI能力 | 说明 |
|------|------|--------|------|
| A | 时间起卦 | AI完全自主（有系统时间） | 最推荐，最自然客观，无需用户额外输入 |
| B | 数字起卦 | 用户提供数字，AI计算 | 两数法或三数法，用户报数即可 |
| C | 文字起卦 | 用户提供文字，AI查笔画 | 用户输入1-N个字，AI按繁体笔画起卦 |
| D | 外应转述起卦 | 用户描述感知到的外应，AI转换 | 用户将自己看到/听到的现象告诉AI，AI按梅花易数规则转换为卦数 |

**展示话术示例：**

```
请选择起卦方式：

A. 时间起卦 — 我直接用当前时间起卦（最推荐，最自然客观）
B. 数字起卦 — 您报两三个数字，我来计算
C. 文字起卦 — 您输入几个字，我查繁体笔画起卦
D. 外应转述起卦 — 您描述刚才看到/听到的特殊现象（如听到几声敲门、来人从哪个方向来、看到什么颜色的东西），我来转换

请回复 A/B/C/D。
```

#### 重要说明（必须遵守）

AI 没有听觉、视觉，无法独立感知声音、方位、颜色、动物、物品。

- 声音起卦、方位起卦、颜色起卦、动物起卦、物品起卦这些传统方式，只有在**用户主动描述外应**时才能使用，本质是"用户感知 → 转述给 AI → AI 转换为数字 → 起卦"
- AI 本身不具备任何感知能力，绝不可编造外应
- 如果用户没有外应可描述，推荐使用时间起卦(A)或数字起卦(B)
- 当用户选择 D（外应转述起卦）时，必须明确询问："请描述您感知到的现象（听到几声什么声音 / 来人从什么方向来 / 看到什么颜色或动物或物品）"

#### 各方法输入收集

**选择 A（时间起卦）：**
- AI 自主获取当前系统时间（公历），转换为农历年月日时
- 无需用户额外输入
- 直接进入阶段3

**选择 B（数字起卦）：**
- 询问用户："请报出数字。您可以用两数法（报两个数字）或三数法（报三个数字）。"
- 收集用户提供的数字（2个或3个正整数）
- 确认数字后进入阶段3

**选择 C（文字起卦）：**
- 询问用户："请输入您想用来起卦的文字（可以是一个字、两个字或多个字）。"
- 收集用户提供的文字
- AI 查阅繁体笔画表（见第二章"文字起卦法"内置笔画表），对表中没有的字，AI 根据康熙字典繁体笔画规则推算
- 确认笔画后进入阶段3

**选择 D（外应转述起卦）：**
- 询问用户："请描述您刚才感知到的特殊现象，例如：
  - 听到声音：'我听到3声敲门'
  - 来人方位：'来人从东方来'
  - 看到颜色：'看到一件红色衣服'
  - 看到动物：'看到一只黑色的鸟'
  - 看到物品：'桌上有一个圆形铜器'"
- 收集用户描述，AI 按外应转换规则（见第二章"外应转述起卦法"）转换为卦数
- 确认转换结果后进入阶段3

### 阶段3 — 执行起卦计算（含验证清单）

按所选方法的精确公式计算上卦、下卦、动爻，确定本卦/互卦/变卦，确定体卦/用卦，分析五行生克、旺衰、应期。每步执行验证清单（见第九章）。

**计算流程：**

1. 计算上卦数 → 查先天八卦表 → 确定上卦
2. 计算下卦数 → 查先天八卦表 → 确定下卦
3. 计算动爻数 → 确定动爻位置（1-6）
4. 由上卦+下卦 → 查64卦表 → 确定本卦（卦名、卦序）
5. 由本卦第2,3,4爻和第3,4,5爻 → 确定互卦
6. 动爻阴阳翻转 → 确定变卦
7. 由动爻位置确定体卦和用卦
8. 查体卦、用卦五行 → 确定生克关系
9. 查当前季节 → 确定体卦旺衰状态
10. 计算体用合数 → 确定应期
11. 逐项执行验证清单
12. 进入阶段4

### 4种起卦法公式

#### 1. 时间起卦法（AI完全自主，最推荐）

AI 直接获取当前系统时间的年月日时，无需用户输入。

**公式：**
```
年支序数 = (公历年份 - 4) % 12 + 1    // 结果1-12，对应子1丑2...亥12
月数 = 当前月份（1-12）
日数 = 当前日期（1-31）
时支序数 = 根据当前小时查时辰对照表（1-12）

上卦数 = (年支序数 + 月数 + 日数) % 8
  → 若余数为0，取8（坤卦）
下卦数 = (年支序数 + 月数 + 日数 + 时支序数) % 8
  → 若余数为0，取8（坤卦）
动爻 = (年支序数 + 月数 + 日数 + 时支序数) % 6
  → 必须用年月日时四项"总和"直接除6，严禁用下卦数（总和除8后的余数）代替
  → 若余数为0，取6（上爻）
```

**示例：**
```
当前时间：2026年8月8日 15:30
年支序数 = (2026 - 4) % 12 + 1 = 2022 % 12 + 1 = 6 + 1 = 7（午）
月数 = 8
日数 = 8
时支序数 = 申时 = 9（15:00-17:00）

上卦数 = (7 + 8 + 8) % 8 = 23 % 8 = 7 → 艮卦 ☶（山）
下卦数 = (7 + 8 + 8 + 9) % 8 = 32 % 8 = 0 → 取8 → 坤卦 ☷（地）
动爻 = (7 + 8 + 8 + 9) % 6 = 32 % 6 = 2 → 第二爻动（用总和32，不用下卦数8）

本卦：山地剥（上艮下坤）
```

**注意：** 如果 AI 运行环境支持获取农历，应优先使用农历年月日时。传统梅花易数用农历，月用农历月份数(1-12)，日用农历日数(1-30)。如无法获取农历，使用上述公历近似法，并在报告中注明。

**判别性示例（专门暴露"用下卦数算动爻"的错误）：**
```
时间：2026年3月5日 15:30（申时）
年支序数=7，月数=3，日数=5，时支序数=9
上卦数 = (7+3+5) % 8 = 15 % 8 = 7 → 艮卦
下卦数 = (7+3+5+9) % 8 = 24 % 8 = 0 → 取8 → 坤卦
本卦：山地剥

正确动爻 = 24 % 6 = 0 → 取6 → 上爻动
错误动爻 = 8 % 6 = 2 → 二爻动   ← 用下卦数8（除8后的余数）算出的错卦
```
> 此例中两种算法一动在上爻、一动在二爻，体用归属与全卦结论完全不同。凡时间总和能被8整除、或"总和与下卦数之差不是6的倍数"时，错误算法必然露馅。起卦后必须用此思路反向自检一次。

#### 2. 数字起卦法（用户提供数字）

**两数法** (输入 a, b 两个正整数)：
```
上卦 = a % 8    → 余0取8
下卦 = b % 8    → 余0取8
动爻 = (a + b) % 6    → 余0取6
```

**示例（两数法）：**
```
用户报数：168, 349
上卦 = 168 % 8 = 0 → 取8 → 坤卦 ☷（地）
下卦 = 349 % 8 = 5 → 巽卦 ☴（风）
动爻 = (168 + 349) % 6 = 517 % 6 = 1 → 第一爻动

本卦：地风升（上坤下巽）
```

**三数法** (输入 a, b, c 三个正整数)：
```
上卦 = a % 8    → 余0取8
下卦 = b % 8    → 余0取8
动爻 = c % 6    → 余0取6
```

**示例（三数法）：**
```
用户报数：213, 423, 123
上卦 = 213 % 8 = 5 → 巽卦 ☴（风）
下卦 = 423 % 8 = 7 → 艮卦 ☶（山）
动爻 = 123 % 6 = 3 → 第三爻动

本卦：风山渐（上巽下艮）
```

#### 3. 文字起卦法（用户提供文字，AI查笔画）

以康熙字典繁体笔画为准。

**一字起卦：**
```
总笔画 N
若 N 为偶数：上卦数 = (N/2) % 8，下卦数 = (N/2) % 8
若 N 为奇数：上卦数 = ((N-1)/2) % 8，下卦数 = ((N+1)/2) % 8
  → 半幅笔画也必须除8取余，余0取8（卦数超出8时如18画半=9、24画半=12，不除8会得到非法卦数）
动爻 = N % 6    → 余0取6
```

**示例（一字法）：**
```
用户输入："福"
查表：福→14画（繁体）
N=14（偶数）：上卦 = 14/2 = 7 → 艮卦 ☶（山）
              下卦 = 14/2 = 7 → 艮卦 ☶（山）
动爻 = 14 % 6 = 2 → 第二爻动

本卦：艮为山（上艮下艮）
```

**两字起卦：**
```
第一字笔画 P1 → 上卦 = P1 % 8    → 余0取8
第二字笔画 P2 → 下卦 = P2 % 8    → 余0取8
动爻 = (P1 + P2) % 6    → 余0取6
```

**示例（两字法）：**
```
用户输入："发财"
发→發12画，财→財10画
上卦 = 12 % 8 = 4 → 震卦 ☳（雷）
下卦 = 10 % 8 = 2 → 兌卦 ☱（泽）
动爻 = (12 + 10) % 6 = 22 % 6 = 4 → 第四爻动

本卦：雷泽归妹（上震下兌）
```

**三字以上起卦：**
```
将文字分为前半和后半
前半总笔画 S1 → 上卦 = S1 % 8    → 余0取8
后半总笔画 S2 → 下卦 = S2 % 8    → 余0取8
动爻 = (S1 + S2) % 6    → 余0取6

注意：
- 三字：前半=第1字，后半=第2,3字
- 四字：前半=第1,2字，后半=第3,4字
- 五字：前半=第1,2字，后半=第3,4,5字
- 奇数个字时，前半少一个字（(N-1)/2 个），后半多一个字（(N+1)/2 个）
```

**示例（多字法）：**
```
用户输入："万事如意"
万→萬15画，事→事8画，如→如6画，意→意13画
前半（万、事）：S1 = 15 + 8 = 23
后半（如、意）：S2 = 6 + 13 = 19
上卦 = 23 % 8 = 7 → 艮卦 ☶（山）
下卦 = 19 % 8 = 3 → 离卦 ☲（火）
动爻 = (23 + 19) % 6 = 42 % 6 = 0 → 取6 → 上爻动

本卦：山火贲（上艮下离）
```

#### 4. 外应转述起卦法（用户描述外应，AI转换）

AI 无法独立感知外应，但当用户描述自己感知到的现象时，AI 按以下规则转换。

> **本质说明：** 外应转述起卦的本质是"用户感知 → 描述 → AI 转换为数字 → 起卦"，AI 本身不具备任何感知能力。如果用户没有外应可描述，应引导使用时间起卦或数字起卦。

##### 4.1 用户描述声音次数

**单段声音**（如"我听到3声敲门"）：
```
上卦数 = n % 8    → 余0取8（声音次数超过8也必须归一）
下卦数 = (n + 当前时支序数) % 8    → 余0取8
动爻 = (n + 当前时支序数) % 6    → 余0取6
```

**示例：**
```
用户描述："我刚听到5声敲门"
当前时支序数 = 9（申时）
上卦 = 5 → 巽卦 ☴（风）
下卦 = (5 + 9) % 8 = 14 % 8 = 6 → 坎卦 ☵（水）
动爻 = (5 + 9) % 6 = 14 % 6 = 2 → 第二爻动

本卦：风水涣（上巽下坎）
```

**两段声音**（如"先听到2声，又听到4声"）：
```
前段次数 n1 为上卦 → n1 % 8，余0取8
后段次数 n2 为下卦 → n2 % 8，余0取8
动爻 = (n1 + n2 + 当前时支序数) % 6    → 余0取6
```

#### 体用关系与吉凶判断

| 体用关系 | 含义 | 吉凶 | 特征 |

> - 体卦五行生用卦五行 → 体生用

> - 用卦五行生体卦五行 → 用生体
> - 用卦五行克体卦五行 → 用克体

## 四、卦象推演规则

### 本卦

本卦是起卦后得到的主卦，代表事情的起因与现状。

**确定方法：**
- 上卦 = 第4、5、6爻（从上到下排列：6爻在上，5爻在中，4爻在下）
- 下卦 = 第1、2、3爻（从上到下排列：3爻在上，2爻在中，1爻在下）
- 由上卦数和下卦数查64卦表 → 确定本卦卦名和卦序

**爻的排列规则（从下到上）：**
```
第六爻（上爻）— 最上
第五爻
第四爻
第三爻
第二爻
第一爻（初爻）— 最下
```

**示例：**
```
上卦数=5（巽☴），下卦数=7（艮☶）
巽的三爻（下→上）：阴阳阳
艮的三爻（下→上）：阴阴阳

本卦六爻（从下到上）：
第六爻：阳 ← 巽的上爻
第五爻：阳 ← 巽的中爻
第四爻：阴 ← 巽的下爻
第三爻：阳 ← 艮的上爻
第二爻：阴 ← 艮的中爻
第一爻：阴 ← 艮的下爻

上巽(5) + 下艮(7) → 查表 → 风山渐（第53卦）
```

### 互卦

互卦代表事情的发展过程，由本卦中间四爻重新组合而成。

**取法：**
- 互卦下卦 = 本卦第2、3、4爻（第2爻为初，第3爻为中，第4爻为上）
- 互卦上卦 = 本卦第3、4、5爻（第3爻为初，第4爻为中，第5爻为上）
- 由互卦上卦数和下卦数查64卦表 → 确定互卦卦名

**示例（接上例）：**
```

互卦上卦 = 第3,4,5爻 = 阳,阴,阳（下→上）→ 离☲（火，数3）

互卦：上离(3) + 下坎(6) → 查表 → 火水未济（第64卦）
```

### 变卦

变卦代表事情的结果与走向，由本卦动爻阴阳翻转而成。

**取法：**
- 动爻阴阳翻转（阳变阴，阴变阳）
- 其余5爻保持不变
- 翻转后重新确定上下卦 → 查64卦表 → 确定变卦卦名

**示例（接上例，动爻为第三爻）：**
```
本卦六爻（从下到上）：阴阴阳阳阳阳
动爻 = 第三爻（阳 → 阴）

变卦六爻（从下到上）：阴阴阴阴阳阳
即：第1爻=阴, 第2爻=阴, 第3爻=阴(变), 第4爻=阴, 第5爻=阳, 第6爻=阳

变卦下卦 = 第1,2,3爻 = 阴,阴,阴 → 坤☷（土，数8）
变卦上卦 = 第4,5,6爻 = 阴,阳,阳 → 巽☴（木，数5）

变卦：上巽(5) + 下坤(8) → 查表 → 风地观（第20卦）
```

### 体用确定

体用是梅花易数断卦的核心概念。动爻所在的卦为"用"（所测之事），不动的卦为"体"（我方）。

**规则：**
- 动爻在第1、2、3爻 → 下卦为**用**，上卦为**体**
- 动爻在第4、5、6爻 → 上卦为**用**，下卦为**体**

**示例：**
```
动爻在第三爻 → 下卦（艮）为用，上卦（巽）为体

体卦 = 巽（木）
用卦 = 艮（土）

体卦五行（木）克用卦五行（土）→ 体克用 → 吉
```

**互卦和变卦的体用：**
- 互卦：不分体用，仅看五行生克关系对体卦的影响
- 变卦：动爻已变，体用可能发生转换。若动爻翻转后落入另一卦，则体用互换；若仍在原卦，则体用不变

### 应期推算

应期是预测事情发生的大致时间。

**计算方法：**
```
体用合数 = 体卦先天数 + 用卦先天数
```

**判断：**
- 近期之事：体用合数 ≈ 天数（如合数为9，则约9天后应验）
- 远期之事：体用合数 ≈ 月数（如合数为9，则约9个月后应验）

**辅助判断：**
- 旺相之卦应期快（当令有力，事易成）
- 休囚之卦应期慢（失令无力，事迟缓）
- 用生体则应期快（有外援推动）
- 用克体则应期慢或不应（阻力大）

**示例：**
```
体卦巽（先天数5）+ 用卦艮（先天数7）= 合数12

若为近期之事：约12天后有结果
若为远期之事：约12个月后有结果

体卦巽木在秋季为囚（弱），应期可能偏慢
```

#### 三个卦象的SVG绘制规则

**本卦SVG**：
- 有动爻标记（圆点 + accent颜色）
- 动爻保持本卦原阴阳

**互卦SVG**：
- 无动爻标记
- 所有爻按互卦实际阴阳绘制

**变卦SVG**：
- 动爻位置有标记（圆点 + accent颜色）
- 动爻已翻转（阳变阴或阴变阳）
- 其余爻按变卦实际阴阳绘制

  对于 i 从 0 到 5:
    y = Y坐标[i]
    爻位 = i + 1  // 1=初爻, 6=上爻
    是否动爻 = (动爻位置 == 爻位) && 是否标记动爻
    
    如果 六爻数组[i] == "阳":
      如果 是否动爻:
        输出 '<line class="yang-line" x1="10" y1="{y}" x2="70" y2="{y}" style="stroke: var(--accent);"/>'
        输出 '<circle class="moving-mark" cx="40" cy="{y}" r="5"/>'
      否则:
        输出 '<line class="yang-line" x1="10" y1="{y}" x2="70" y2="{y}"/>'
    
    如果 六爻数组[i] == "阴":
      如果 是否动爻:
        输出 '<line class="yin-line-left" x1="10" y1="{y}" x2="36" y2="{y}" style="stroke: var(--accent);"/>'
        输出 '<line class="yin-line-right" x1="44" y1="{y}" x2="70" y2="{y}" style="stroke: var(--accent);"/>'

## 九、防错验证清单

每次起卦后，必须逐项核对以下验证清单。任何一项不通过，需重新检查计算。

### 起卦验证

| 验证项 | 检查内容 | 通过条件 |
|--------|---------|---------|
| 上卦余数 | 上卦数 % 8 的余数是否正确 | 余数在1-8范围内 |
| 上卦余0处理 | 若余数为0，是否取8 | 余0→取8（坤卦） |
| 下卦余数 | 下卦数 % 8 的余数是否正确 | 余数在1-8范围内 |
| 下卦余0处理 | 若余数为0，是否取8 | 余0→取8（坤卦） |
| 卦数%8归一 | 所有取卦路径是否都做了%8（余0取8），包括一字起卦的N/2半幅笔画、单段声音次数n | 卦数必须落在1-8，禁止出现9以上的直接卦数 |
| 动爻取数来源 | 动爻是否用"未取余的原始总和"计算：时间法=年支+月+日+时支总和；外应方位/颜色/动物/物品法=上卦数+时间总和；数字两数法=a+b（三数法=c）；文字法=总笔画N；声音单段=n+时支、两段=n1+n2+时支 | 严禁用下卦数（除8后的余数）参与动爻计算 |
| 动爻独立重算 | 用原始输入重新独立算一遍动爻，再与报告值比对（不能只对照公式自我打勾） | 两次结果一致方可通过 |
| 动爻余数 | 动爻数 % 6 的余数是否正确 | 余数在1-6范围内 |
| 动爻余0处理 | 若余数为0，是否取6 | 余0→取6（上爻） |
| 年支推算 | 年支序数是否按 (公历年份-4)%12+1 推算 | 严禁用"年份末位"查地支；立春前按上一年 |
| 64卦查询 | 上卦数(行) × 下卦数(列) 查表结果是否正确 | 卦名与卦序匹配 |
| 动爻范围 | 动爻位置是否在1-6范围内 | 1≤动爻≤6 |
| 体用对应 | 动爻在1-3爻→下卦为用上卦为体；动爻在4-6爻→上卦为用下卦为体 | 体用判定正确 |
