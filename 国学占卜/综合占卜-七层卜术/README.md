# 综合占卜-七层卜术

术数占卜全技能包。以古籍原文库为事实底座、规则库为判断依据、脚本为零差错排盘工具，按问题自动路由到对应术数门。

## 用途

一站式处理命理、占事、吉凶速断、看相相地、择日、谋略、解梦七类请求。先过问诊关，再进对应层，断语可溯源到典籍出处。

## 覆盖范围（七层）

| 层 | 术 | 解决什么问题 | 深度 |
| --- | --- | --- | --- |
| 命 | 四柱八字（含合婚） | 终身格局、大运流年、事业婚姻大势 | 深做 |
| 事 | 六爻（铜钱卦） | 一件事的来龙去脉、成败、应期 | 深做 |
| 吉 | 小六壬（掌诀） | 当下吉凶定性，速断 | 深做 |
| 相 | 人相（麻衣）+ 地相（形法） | 观人气质格局；相宅相地形势 | 中做 |
| 时 | 择日（协纪体系） | 嫁娶、开业、动土、出行宜忌 | 够用 |
| 局 | 奇门遁甲 + 大六壬 | 大事谋略、时机方位选择 | 入门 |
| 民俗 | 解梦（梦林玄解）+ 民俗占验 | 梦象释义、民俗事象吉凶 | 入口 |

五相进度：命、卜（事＋吉＋局）、相 三块已齐；山、医 不在本包范围。

## 内部结构（迁入后）

```text

├── SKILL.md

├── 原文库/      # 古籍原文，用于出处核对（三命通会、滴天髓、增删卜易、麻衣神相等）
└── script/      # 干支、六爻、农历、神煞、八宅计算脚本
```

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型触发语句：算命、占卜、合婚、问事、起卦、看相、风水、择日、解梦、问运势、断吉凶、看应期。

排盘必须走脚本，不心算；断语只从规则库与原文库出，每条标注出处。

## 能力边界

1. 不占生死寿夭、他人隐私、赌博非法之事；
2. 疾病占只断趋势并提示就医，不做诊断；
3. 奇门精断、紫微深解、理气实断超出本包深度，明说边界，不硬装；
4. 用户出现情绪危机时立即停止术数输出，转向就医与心理援助建议。
