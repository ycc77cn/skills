## 〇、起卦规范

**起卦方式判定（AI 依条件定，不问用户偏好，只问事实“手边有三枚硬币吗”）：**
① 手边有三枚硬币/铜钱 → **摇卦（正法）**
② 无道具、能报数 → **报数卦**（代用法，见第 4 条）
③ 不能报数（深夜/打字慢/情绪激动）且本辰未起过卦 → **时间卦**（代用法，见第 3 条）
④ 报数纠结/迟疑，或本辰已起过卦（同辰必同卦）→ **随手卦**（一个数，见第 5 条）
⑤ 全不便 → 等换辰（最后兜底，告知即可）
优先级：**摇 > 报 > 时**（随手卦为报数纠结/本辰已占时的出口，见第 5 条；等换辰为最后兜底）——用户的手参与越多，心念越专一；连占第二卦默认走报数/随手（时间卦同辰不可用），**AI 直接定，不问偏好**；豁免永不指向死路

**以钱代蓍法（出自《卜筮正宗·卷之一 以钱代蓍法》+《增删卜易·002 占卦法》）：**
1. 用户摇卦：三枚硬币摇六次，从下往上（初爻至上爻）记录。**铜钱不必古钱，三枚同面值硬币（如一元硬币）即可：字面为“字”、花面为“背”**。**铜钱→爻象换算表（硬表，照表换算禁止心算）**：

| 摇出结果 | 术语 | 画作 | 四态码 | 性质 |
|----------|------|------|--------|------|
| 三背（零字） | 重 | ○ | 3 | 老阳，动爻，变阴 |
| 二背一字 | 拆 | ″ | 2 | 少阴，静爻 |
| 一背二字 | 单 | ′ | 1 | 少阳，静爻 |
| 三字（零背） | 交 | × | 0 | 老阴，动爻，变阳 |

> （出自《增删卜易·002 占卦法》原文："一个背，两个字，称作'单'……为少阳。两个背，一个字，称作'拆'……为少阴。三个背，没有字，称作'重'……为老阳，是变爻。三个字，没有背，称作'交'……为老阴，是变爻。"）
> **注意：背与字是反向计数**——"一字"等于"二背"（是少阴），"二字"等于"一背"（是少阳）。用户按"几个字几个背"口述时须按本表行整行匹配，不得只据"字数"或只据"背数"单独推断。
2. 用户提供摇卦结果（如"初爻一背二字、二爻两背一字……"）→ **逐爻查上表**换算四态爻串（0老阴/1少阳/2少阴/3老阳）→ 送 `script/liuyao.js` 装卦
3. 时间卦（文字起卦，**代用法——铜钱摇卦为正法，准确度以摇卦为佳，输出时向用户说明**）：**取数公式（四变数缺一不可，禁心算替代查表）**：年数＝农历年地支序（子1丑2寅3卯4辰5巳6午7未8申9酉10戌11亥12）、月数＝农历月、日数＝农历日、时数＝时辰序（子1…亥12；农历月日查 `script/nongli.js` 公历模式）→ 上卦＝（年＋月＋日）÷8 取余（余0取8）、下卦＝（年＋月＋日＋时）÷8 取余（余0取8）、动爻＝（年＋月＋日＋时）÷6 取余（余0取6）；卦按先天八卦数定（公共库bagua.md：乾1兑2离3震4巽5坎6艮7坤8）得卦与动爻位 N → **硬映射转四态串，禁止凭感觉拼串**：查《公共库/guaming.md》得本卦六爻阴阳——动爻位：阳爻→3（老阳，变阴）、阴爻→0（老阴，变阳）；其余静爻：阳→1（少阳）、阴→2（少阴）→ 送 `script/liuyao.js` 装卦。**同辰限用（硬限制）**：时间卦四变数为年/月/日/时，同一时辰四数全同、第二卦必得同卦——时间卦仅限本辰首卦；本辰已起过卦（不论同事异事）再占，禁用时间卦，改摇卦/报数卦/随手卦
   例：2026年10月21日（农历丙午年九月十二）申时起卦：年午＝7、月＝9、日＝12、时申＝9 → 上卦 28÷8 余4＝震、下卦 37÷8 余5＝巽、动爻 37÷6 余1＝初爻 → 雷风恒初爻动（初爻阴动→老阴0，静爻阳1阴2，四态串 **011122**）→ 雷风恒之雷天大壮
4. **报数卦（代用法，起法出梅花易数体系——只借起法，断卦一律六爻纳甲）**：请用户当下随心报 3 个数（每个 1–999）——**引导话术：“数字没有对错，随便报三个，报完不许改——越随意越灵，别想”**（不商量、不挑选、报完不改）→ 上卦=数一÷8 取余（余 0 取 8）、下卦=数二÷8 取余（余 0 取 8）、动爻=数三÷6 取余（余 0 取 6）→ 按第 3 条同款硬映射转四态串 → 送 `script/liuyao.js` 装卦，输出时声明代用法精度（同时间卦）。**选择困难豁免（永不指向死路）**：用户明显迟疑、反复改数、问“报什么好”，或纠结超过 30 秒 → 本辰未起过卦改用时间卦（说明：“这卦取您当下的时辰，不用您选——心到即可”）；本辰已起过卦改用随手卦（见第 5 条）。**代占（为他人占）**：数由**本主报最真**（心念在彼）；本主不在场/不便，代占者持其事于心随口报亦可（增删卜易体例，代占是正门），报前声明“此卦为某人某事而占”；代占者报数纠结 → 首选请本主报，本主不便则走随手卦
  例：报 3、5、7 → 上离（3）下巽（5）初爻动（7÷6 余 1）= 火风鼎；鼎六爻为初阴、二阳、三阳、四阳、五阴、上阳 → 四态串 **011121**（初爻动→0，其余静爻阳 1 阴 2）→ 火风鼎之火天大有
5. **随手卦（外应法，代用法，起法出梅花易数“物数占/三要灵应”体例——只借起法，断卦一律六爻纳甲）**：无硬币、报数纠结、本辰时间卦不可用时的出路。引导话术：“别挑别想——此刻眼前第一眼看到的那个数报给我就行：车牌尾号、价格牌、书页码、手机电量，看见什么报什么”（无心之应为真，环境替你选，选择困难免疫）→ 得数一（1–999，超三位取末三位）→ 上卦=数一÷8 取余（余 0 取 8）、下卦=（数一+当前时支数）÷8 取余（余 0 取 8）、动爻=（数一+当前时支数）÷6 取余（余 0 取 6）→ 按第 3 条同款硬映射转四态串 → 送 `script/liuyao.js` 装卦，输出时声明代用法精度。时辰变数由系统自动取（查 script/nongli.js 今天），用户只需一个数；数不同则卦不同，同辰连占互不冲突
  例：随眼看车牌尾号 47，当前巳时（时支数 6）→ 上卦 47÷8 余 7=艮、下卦 53÷8 余 5=巽、动爻 53÷6 余 5=五爻动 → 山风蛊；蛊六爻为初阴、二阳、三阳、四阴、五阴、上阳 → 五爻阴动→老阴 0，四态串 **211201** → 山风蛊之巽为风
6. **摇卦纪律（增删卜易体例）**：一事一卦，心诚则灵之实质为“意念专一”；同一事短时内反复占（三卦以上），以首卦为准；**换起卦方式重占视同反复占，同以首卦为准**（答案不合心意不得换方式重摇——易学通则《易·蒙》“初筮告，再三渎，渎则不告”）；**再占唯一合法条件=卦象信息不足**（用神不明/爻象冲突），重占之卦只作辅证不作翻案。**“事”的粒度与连占**：一事一卦=每件事一卦，**不是一次会话一卦**——换新事（感情→事业→另一件事）随时起新卦，互不占用，**禁止以“一事一卦”为由拒绝新事起卦**；同一件事的不同侧面（同一感情的“能不能成/心意如何/有没有外人”）视为一事，从首卦继续看（一卦多断），不另起卦——被拦时必须给路径：“此事已有卦在桌，要看的侧面从原卦给您断”，不得只拒不给路
7. 占卦必须用求测人实际**起卦时刻**的干支断日月（摇卦/报数/时间卦/随手卦同此，脚本输入当日日期）

## 二、察衰旺（四处生克之法）

**三元神体系（出自《增删卜易·009 用神、元神、忌神、仇神》）：**
- **元神**：生用神之爻（如用神财，则子孙为元神）
- **忌神**：克用神之爻
- **仇神**：克元神、生忌神之爻
- 断：元神旺动生用则吉顺；忌神旺动克用则阻滞；仇神为间接恶化因素

**衰旺三查顺序：**
1. **月建为提纲（出自《增删卜易·017 月将》："月将掌一月之权，司三旬之令……操持万卜之提纲，巡查六爻之善恶……月建乃当权之主帅，万卜以之为纲领"）**：用神与月建的生克（当令/休囚）、月破（用神与月建相冲，出自《增删卜易·034 月破》——月破之爻，出月可用，当月事难成）
2. **日辰为主宰（出自《增删卜易·018 日辰》，"日辰为六爻之主宰"）**：日辰冲（暗动/冲散）、合（合住）、生克、墓（用神入日墓）、旬空（出自《增删卜易·029 旬空》——"用遇旬空近病何须忧虑；用逢月破久病难许安宁"）
3. **动爻变爻（出自《增删卜易·014 动静生克 + 007 动变、013 克处逢生》）**：动爻能生克他爻，静爻不能；变爻回头生克本动爻（回头生/回头克）；克处逢生为凶中有救

> **查表纪律（与排盘禁心算同律）：干支关系——合/冲/刑/害/十二长生（生旺墓绝）——判定前一律查《公共库/干支五行.md》对应表，禁止凭记忆心算。六合仅六组：子丑/寅亥/卯戌/辰酉/巳申/午未。实测教训：曾把“酉金绝于寅日”错判为“寅酉合”（寅酉不合），硬伤。**

> **旬空取用：旬空字段直接取 `script/liuyao.js` 输出中的“旬空”值（如戌亥），不再另调 nongli.js——装卦与断卦同一口径。**

## 四、推应期（六爻独有强项）

**总纲（出自《增删卜易·032 各门类应期总注》）：**
- 爻静 → 应于**值日**（逢其地支之日）或**冲日**（冲动之日）
- 爻动 → 应于**合住之日**（动逢合则绊，逢冲之期解绊）或值日
- 旬空 → 应于**出空之日**（出旬）或**冲空/填实之日**
- 月破 → 应于**出月**或**实破**（逢值）之日
- 墓 → 应于**冲开墓库之日**
- 绝 → 应于**生我之日**
- 事缓应月、事急应日、更急应时辰

> 应期断语格式：`X事应期，应期窗口在X（日/月支值冲）前后` ——只给窗口不给判决，禁“必见分晓/躲不过/迟早”类判决词（措辞纪律见第七节第9条与 SKILL.md 输出铁律第7条）；不做精确到事件内容层面的预言。
