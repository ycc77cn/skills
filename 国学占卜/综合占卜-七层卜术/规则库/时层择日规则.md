# 时层·择日规则（够用档）

> 主库：《协纪辨方书》（钦定官修择日大典，四库本三十六卷全本已入库：本原/义例/立成/宜忌/公规/利用/附录/辨伪）。注：卷二十~三十一为年表图表卷，文本版仅存表头条文；逐日逐年推排查原书扫描。重大择日（婚丧大课）仍提示人工复核。

## 〇、择日总流程（固定五步）

1. **定事类**：嫁娶 / 开业开市 / 动土修造 / 搬家入宅 / 出行上任 / 签约谈判（六类为本层覆盖面；其余事项按相近类套用并说明）
2. **取候选日**：用户给时间范围，**逐日调 `script/nongli.js 干支 YYYY-MM-DD`**（输出日干支/旬空/农历），列出范围内各日干支与硬筛字段，禁止心算日柱
3. **排除法校验（硬筛，逐项过）**：
   - 当事人生肖冲日支之日排除（如属鼠（子）遇午日）
   - 当事人命卦方位冲（择日涉方位修造时，岁破/三煞方排除——查公共库shensha.md择日神煞表）
   - 月破日排除（如寅月申日，"月破日百事不宜"——出自协纪通行忌例；**可直接用 `nongli.js 干支` 的"月破判断"字段核验**）
   - 四离四绝日排除（四立前一日、二分二至前一日）
   - 岁破日排除（与当年太岁相冲之支，如子年午日）
4. **宜神核对（加分项）**：候选日按事类核对天德/月德/天德合/月德合/天喜/天医等吉神（查公共库shensha.md）落在日支干者为加分
5. **输出结论**：给出 1-3 个优选日（附理由与出处），明确未核项（如"未核当地民俗忌日、未排嫁娶全套课"）

## 一、六类事择日要点

### 嫁娶（出自《协纪辨方书》嫁娶类目+神煞月令条文）
- 先排双方生年，避开双方生肖冲日；女命为主（古法："嫁娶以女命为要"——注明古法口径）
- 大利月/妨父母月等女命行嫁月体系：本层执行"大利月"速查（按女命生年支查下表），**只避不选凶妨月、不展开全套行嫁月理**（标注"全套课需择日师人工"）
  **大利月速查表**（女命生年支 → 利月；通行口诀"正七迎鸡兔，二八虎与猴，三九蛇共猪，四十龙和狗，五冬牛共羊，六腊鼠共马"）：子午年生 → 六月（未月）、十二月（丑月）；丑未年生 → 五月（午月）、十一月（子月）；寅申年生 → 二月（卯月）、八月（酉月）；卯酉年生 → 正月（寅月）、七月（申月）；辰戌年生 → 四月（巳月）、十月（亥月）；巳亥年生 → 三月（辰月）、九月（戌月）。**出处与争议声明**：体系为民间行嫁月口诀（玉匣记一脉）；《协纪辨方书·辨譌》将"合婚大利月"列为术士谬说**驳斥**（官修立场不采，原文"术士捏造益属荒唐"）——本技能按民俗参考执行并标注争议，全套课仍需择日师人工
- 忌：月破、受死日（民俗忌例）

### 开业开市
- 喜财星临日（日支或日干为当事人生年三合财禄方）
- 忌月破、四绝；开市时辰避开当日冲时

### 动土修造（出自《协纪辨方书》修造类目+"修造取土"月令条文）
- 先核**方位**：当年三煞方、太岁方、岁破方不动土（公共库择日神煞表）；月家神煞按协纪月令条文体例（原文库协纪前段逐月条文可查）
- 忌：月破日动土、土王用事后（民俗忌深掘）

### 搬家入宅
- 宜天德月德日、天喜日；忌月破、与宅主生肖冲日
- 入宅时辰选当日吉时（避开冲宅主时支）

### 出行上任
- 宜驿马日、天德月德日；忌赤口时（民俗层小六壬可速断）、月破出行
- 远行另核四离四绝

### 签约谈判
- 宜定日（地支与值日建除十二神之"定"）、合日；忌月破
- 建除十二神：**逐日调 `script/nongli.js 干支 YYYY-MM-DD` 取"建除十二神/月建/月破判断"字段（禁止心算；交节日自动给节前节后双口径）**；吉凶口诀——建满平收黑、除危定执黄、成开皆可用、破闭不相当（民俗建除口诀，其系统体系见协纪，本层只取此速查级）

## 二、择日神煞查证顺序

1. 先查凶神（排除法）：月破 > 岁破 > 四离四绝 > 冲生肖命卦 —— 凶神一票否决
2. 再查吉神（优选法）：天德/月德 > 天德合/月德合 > 天愿/天喜/天医（事类对应）
3. 吉凶并见：**吉足胜凶、吉不抵凶从其重**（协纪辨方书通例：神煞轻重以"制煞"理论衡，本层简化为"多吉胜少凶、大煞一票否"）
