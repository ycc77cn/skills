# 术数占卜全技能（divination-master）

八层卜术一站式占断技能。以古籍原文库为事实底座、规则库为判断依据、脚本为零差错排盘工具，按问题自动路由到对应术数门，断语可溯源到典籍出处。

## 用途

一站式处理终身命理、具体问事、吉凶速断、看相相地、择日、谋略决策、符箓查典、解梦占验八类请求。先过问诊关，再进对应层；排盘交给确定性脚本，断语只从规则库与原文库出。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型触发语句：算命、占卜、合婚、问事、起卦、看相、风水、择日、解梦、问运势、断吉凶、看应期、查符箓。

执行纪律三条：

1. 先过问诊关（一事一问、对象明确、缺信息回问），不过关不起卦；
2. 排盘只信脚本不信心算，脚本按技能包绝对路径调用；
3. 断语只从规则库/原文库来，每条带典籍出处，超出库内规则明说不编。

## 能力边界

1. 不占生死寿夭、他人隐私侵害、赌博非法之事；出现情绪危机立即停止术数输出，转向就医与心理援助；
2. 疾病占只断趋势并提示就医，一律以医院诊断为准，不做诊断；
3. 奇门精断、紫微深解、理气实断超出本包深度档位，明说边界不硬装；
4. 山术符箓为典籍文化参考、仅供研究：AI 不画符、不代做、不引导付费化解，效果表述固定为「符箓在书中记载可以有什么效果，但 skill 制作者并未亲身尝试，并不知晓是否有效」；
5. 民俗与合婚场景禁吓人、禁二值判决、禁绝对语，重大事项提示结合现实理性判断。
