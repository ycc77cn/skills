# 公共库·六亲定义与基本象

> 用途：六爻装卦定六亲、八字十神对照参考。"六亲"在六爻与八字中含义不同：六爻六亲按卦宫五行与爻支五行的生克定名；八字十神按日干与各干支五行定名。两者**不可混用**。

## 一、六爻六亲（以卦宫五行为"我"）

| 六亲 | 定义（以卦宫五行为我） | 关系方向 |
|------|----------------------|----------|
| 父母 | 生我者 | 生我者为父母 |
| 兄弟 | 同我者（同五行） | 同我为兄弟 |
| 子孙 | 我生者 | 我生者为子孙 |
| 妻财 | 我克者 | 我克者为妻财 |
| 官鬼 | 克我者 | 克我者为官鬼 |

> 《卜筮正宗·装六亲章》：生我者父母，我生者子孙，克我者官鬼，我克者妻财，比和者兄弟。
> 例：乾宫属金，卦中逢亥子水爻为我生者→子孙，逢寅卯木爻为我克者→妻财。

### 六亲基本象（断卦取用方向）

| 六亲 | 人物象 | 事物象（常用） |
|------|--------|----------------|
| 父母 | 长辈、父母、师长、文书之人 | 房屋、车船、文章、契约、手续、单位；辛苦操劳 |
| 兄弟 | 平辈、兄弟、朋友、竞争者 | 同行、阻隔、破财之端、合伙 |
| 子孙 | 晚辈、子女、学生、医药之人 | 解忧之神、僧道、宠物、玩乐、药饵 |
| 妻财 | 妻、女性对象、雇员 | 钱财、货物、饮食、器物 |
| 官鬼 | 丈夫、官长、上司、执法者 | 官职、功名、疾病、忧患、雷霆鬼神 |

> 取用总纲（增删卜易）：**问何人何事，先定用神**。如问父母之事以父母爻为用神，问妻财以妻财爻为用神……完整分类取用规则见《规则库/事层六爻规则.md》。

## 二、八字十神（以日干为"我"）

| 十神 | 定义（以日干五行为我） | 阴阳要求 |
|------|----------------------|----------|
| 比肩 | 同我、同阴阳 | 甲见甲 |
| 劫财 | 同我、异阴阳 | 甲见乙 |
| 食神 | 我生、同阴阳 | 甲见丙 |
| 伤官 | 我生、异阴阳 | 甲见丁 |
| 偏财 | 我克、同阴阳 | 甲见戊 |
| 正财 | 我克、异阴阳 | 甲见己 |
| 七杀（偏官） | 克我、同阴阳 | 甲见庚 |
| 正官 | 克我、异阴阳 | 甲见辛 |
| 偏印（枭神） | 生我、同阴阳 | 甲见壬 |
| 正印 | 生我、异阴阳 | 甲见癸 |

> 速记：**同性为偏（比肩/食神/偏财/七杀/偏印），异性为正（劫财/伤官/正财/正官/正印）**。即"偏"皆同阴阳，"正"皆异阴阳——十神之名与阴阳严格绑定，排盘时逐位核对。
> 十神含义与格局用法见《规则库/命层八字规则.md》。
