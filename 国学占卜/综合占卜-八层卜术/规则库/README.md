## 冲突处理规则

1. **同层主库冲突**：按上表主库优先级解（命层以千里命稿为最终裁定；六爻以增删卜易为最终裁定）。
2. **跨层不混用**：八字十神与六爻六亲是两套系统（见公共库liuqin.md），断哪个层用哪套。
3. **规则库与公共库冲突**：公共库是排盘表（干支/纳音/神煞查法），规则库是断法；若发现二者字面冲突，以公共库排盘数据为准、规则库断法不变，并在输出中报告该冲突待人工核对。

## 引用格式（硬规定）

每条关键断语末尾标注出处，格式：`（出自《书名·章节名》）`
- 例：（出自《子平真诠·十五 论相神紧要》）
- 例：（出自《增删卜易·091 婚姻》——增删卜易章号以库内博古版编号为准，见事层规则库章号口径说明）
- 原文库文件与章节名一一对应，用户可循此路径查证原文。

## 输出分层（全层统一）

**权威定义见 SKILL.md"输出铁律"节（唯一权威版本，此处不另维护副本）**。要点：大白话结论先行 → 过程与状态（大白话）→ 建议+应期（日历化）→ 技术复核段后置（排盘/卦象结构化展示（脚本输出或人工排盘+声明）→ 取用/格局分析 → 断语逐条带出处）；用户面术语括号白话、断事态不读心。

## 深度档位执行说明

- 深做层：按规则库规则链完整推演，分类占断尽量细化
- 中做层：框架判读为主，细断点到为止
- 够用层（时）：给出宜忌结论+校验过程，复杂课提示人工复核
- 入门层（局/民俗/山）：只展示结构+方向性说明；局层明说"深断需专业"，民俗层执行安全红线；山术层为典籍研究参考（仅供研究声明与效果口径逐字执行，见山术层规则库）

## 通用安全底线（全层适用）

1. 疾病：只建议就医方向（可按六爻病源章断"病在何脏"，但**必附"请以医院诊断为准"**），一律不做生死断
2. 生死寿夭（八字贫贱凶夭篇）：**不执行**该章断语口；用户追问时答"此乃古人研究视角，今不做此断"
3. 他人隐私（占他人婚姻/行踪）：要求提问者说明与对象关系，存疑则拒占
4. 违法赌博：拒占（SKILL.md 术不妄占条款）
5. 精神状态：用户表现出情绪危机 → 立即停止术数输出，引导就医/心理援助
6. 山术/符箓：不画符、不代画、不引导法事与付费化解、不承诺任何效果；涉病问符只作文献罗列＋就医优先（红线全文见《规则库/山术层规则.md》，效果口径逐字执行禁变体）
