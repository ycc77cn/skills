# 提示词

可直接复制使用的提示词文本集合。不按技能规范组织，供人手动取用。

## 分类定位

技能靠 AI 自动识别调用，读的是 `SKILL.md`；提示词靠人主动复制粘贴，读的是 `PROMPT.md`。两套东西分开放，不混在一起。

## 目录结构

```text
提示词/
├── README.md                    # 本文件
└── <用途分类>/                  # 按用途分组，如 写作、角色、分析
    └── <提示词名-用途后缀>/
        ├── PROMPT.md            # 必需。可直接复制的提示词正文
        └── README.md            # 必需。用途、场景、变量、边界
```

提示词数量多、用途杂，允许按用途建二级分类。这与技能目录「只有两层」的规则不同，是本分类的明确例外。

## PROMPT.md 规范

| 项目 | 要求 |
| --- | --- |
| 开头 | 一句话说明这条提示词干什么用 |
| 变量 | 统一用 `{{变量名}}` 占位，每个变量在 `README.md` 里说明含义与填法 |
| 正文 | 复制即可用，不写「请把下面内容发给 AI」这类废话 |
| 长度 | 该多长就多长，不硬凑也不硬删 |
| 敏感信息 | 不含真实姓名、手机号、密钥、内部资料 |
| 跨模型 | 不写死模型名与参数，保持换模型也能用 |

## README.md 规范

固定五段，缺一段视为未完成：

| 段落 | 内容 |
| --- | --- |
| 用途 | 这条提示词解决什么问题 |
| 适用场景 | 什么情况下用，什么情况下别用 |
| 变量说明 | 每个 `{{变量}}` 的含义与填法 |
| 使用方式 | 复制到哪个工具，需要配合什么上下文 |
| 能力边界 | 明确不做什么 |

## 收录规则

1. 只收原创或可自由传播的提示词，不收付费课程与第三方版权内容；
2. 一条提示词一个目录，不把多条塞进同一个文件；
3. 效果不稳定的不入库，宁缺毋滥；
4. 提示词正文与说明分离，正文里不夹解释。
