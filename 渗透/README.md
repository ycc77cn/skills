# 渗透

渗透测试与漏洞挖掘类技能集合。

## 本分类包含

暂无入库技能。

## 预计收录方向

| 方向 | 内容 |
| --- | --- |
| 信息收集 | 资产测绘、接口发现、指纹识别 |
| 漏洞验证 | 越权、注入、逻辑漏洞的验证方法 |
| 代码审计 | 白盒审计流程与常见风险点 |
| 报告输出 | 漏洞报告结构与复现步骤写法 |

## 收录底线

1. 仅用于授权测试，技能内明确标注授权前提；
2. 不收录破坏性利用代码，验证点到为止；
3. 报告以可复现为前提，附最小复现步骤与风险说明；
4. 不收录针对具体厂商未修复漏洞的细节。
