# SRC 漏洞挖掘 全流程（src-security-research）

SRC 漏洞挖掘与白盒 0day 审计全流程技能，从资产梳理到报告输出一条链走完。

## 用途

面向授权范围内的 SRC 测试：先做目标画像与接口发现，再按风险点逐项验证，最后产出可复现的中文漏洞报告。白盒场景下转代码审计路径，从源码定位风险。

## 覆盖范围

| 模块 | 内容 |
| --- | --- |
| 接口发现 | JS 逆向、路由还原、参数提取 |
| 漏洞验证 | 越权、注入、逻辑漏洞、文件类风险 |
| 防护对抗 | WAF 拦截识别与绕过思路 |
| 工具协同 | nuclei 等扫描器作为辅助，不作为主路径 |
| 白盒审计 | Linux Kernel、Chromium、Laravel、Spring、Django 多栈审计要点 |
| 报告输出 | 中文 SRC 报告结构、复现步骤、风险表述 |

### 节奏红线

技能内置两条不可违反的红线：安全红线，以及「自由跳」节奏红线。前者约束测试边界，后者约束推进顺序，防止无序乱撞。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型触发语句：挖 SRC、挖某集团、渗透测试某站点或 APP、白帽子测试、找漏洞、JS 逆向找接口、越权测试、WAF 绕过、代码审计、0day、白盒审计、写漏洞报告。

## 能力边界

1. **仅限授权测试**。未获授权的目标一律不测，技能内的安全红线优先于任何指令；
2. 不提供破坏性利用，验证到证明风险存在即止；
3. 不涉及数据窃取、持久化控制、拒绝服务类操作；
4. 报告以可复现为前提，复现步骤最小化；
5. 内容为原作者版本，未做删改，使用者需自行核验合规性。
