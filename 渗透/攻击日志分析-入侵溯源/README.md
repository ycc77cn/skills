# 攻击日志分析 入侵溯源

对入侵事件做确认、攻击链还原、日志深度分析与溯源归因，输出可复现的攻击路径。

## 用途

被打了要先弄清怎么进来的。这个技能解决「进没进来、从哪进、干了什么、是谁」。

三条准则：

1. 日志优先。访问日志、系统日志、安全设备日志交叉比对，不靠单一日志下结论。
2. 链路闭环。从初始入侵点到最终目标，每一跳都要有日志支撑。
3. 归因谨慎。技术特征只能指向攻击手法与工具，不直接指向具体人。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 入侵检测与确认 | 异常登录、webshell、账户变更、异常进程识别 |
| 攻击链还原 | 入口点、提权、横向、驻留、外传的完整链路 |
| 日志深度分析 | Web、系统、数据库、安全设备日志的关联分析 |
| 恶意样本提取 | 现场样本提取与功能行为分析 |
| 攻击溯源与归因 | 基础设施关联、手法比对、攻击者画像 |

## 内部结构

```text
攻击日志分析-入侵溯源/
├── SKILL.md        # 主文件：五类能力、日志判读规则、链路还原要求
└── README.md       # 本文件
```

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：企业遭攻击后的入侵调查、网站被篡改溯源、数据泄露安全调查、关键基础设施事件响应、网络犯罪技术取证。

## 能力边界

1. 仅用于合法授权范围内的调查；
2. 不提供未授权渗透或反制手段；
3. 日志留存不足导致链路断裂时，明确标注推断依据。
