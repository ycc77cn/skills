# 技能名称：渗透攻击与日志分析

## 技能概述
对遭受黑客攻击的系统进行入侵检测、日志溯源和攻击链还原，分析攻击者的入侵路径、使用的技术手段和造成的危害，为案件侦办和安全加固提供技术支撑。

---

## 核心能力

### 1. 入侵检测与确认
- **入侵迹象识别**：
  - 异常进程和服务（未知的后台进程、异常的服务配置）
  - 异常网络连接（非常规端口的连接、与恶意 IP 的通信）
  - 异常文件（新出现的可执行文件、脚本、工具）
  - 异常账户（新创建的管理员账户、被禁用的安全策略）
  - 异常计划任务（定时执行的恶意脚本、反向 Shell）
- **Web 攻击检测**：
  - SQL 注入攻击日志分析
  - XSS（跨站脚本）攻击检测
  - 文件上传漏洞利用痕迹
  - WebShell 检测与提取
  - 目录遍历攻击痕迹
- **权限提升检测**：
  - 本地提权漏洞利用痕迹（如 CVE 漏洞利用）
  - 内核漏洞利用检测
  - SUID/SGID 滥用检测

### 2. 攻击链还原
- **初始入侵分析**：确定攻击者如何进入系统（钓鱼邮件、漏洞利用、弱口令、供应链攻击）。
- **横向移动追踪**：追踪攻击者在内网中的移动路径（跳板机、内网扫描、横向渗透）。
- **权限提升路径**：还原攻击者从普通用户到管理员权限的提升过程。
- **数据窃取分析**：确定被窃取的数据类型、数量、传输方式和目的地。
- **持久化分析**：识别攻击者留下的后门、持久化机制（注册表启动项、计划任务、Rootkit）。
- **清除痕迹分析**：检测攻击者清除日志、删除文件、修改时间戳的行为。

### 3. 日志深度分析
- **系统日志分析**：
  - Windows 事件日志（安全、系统、应用程序日志）
  - Linux 系统日志（/var/log/auth.log、/var/log/syslog、journalctl）
  - 认证日志（登录成功/失败、SSH、RDP）
- **Web 服务器日志**：
  - Nginx/Apache 访问日志和错误日志
  - IIS 日志
  - WAF（Web 应用防火墙）日志
- **数据库日志**：
  - 慢查询日志
  - 通用查询日志
  - 审计日志
- **网络设备日志**：
  - 防火墙日志
  - IDS/IPS 日志
  - 路由器/交换机日志
- **应用日志**：
  - 中间件日志（Tomcat、WebLogic、JBoss）
  - 自定义应用日志

### 4. 恶意样本提取与分析
- **WebShell 提取**：从 Web 目录中提取后门文件，分析其功能。
- **恶意脚本分析**：分析 PowerShell、Python、Bash 等恶意脚本的行为。
- **后门程序分析**：分析植入的后门程序（如 Gh0st、Cobalt Strike Beacon）。
- **Rootkit 检测**：检测内核级和用户级的 Rootkit。

### 5. 攻击溯源与归因
- **IP 追踪**：追踪攻击来源 IP，关联代理链、VPN、Tor 出口节点。
- **C2 服务器分析**：分析命令与控制（C2）服务器的域名、IP、通信协议。
- **攻击者画像**：根据攻击手法、工具特征、时间规律等推断攻击者类型（APT 组织、黑客团伙、个人黑客）。
- **威胁情报关联**：将攻击指标（IoC）与威胁情报库关联，匹配已知攻击组织。

---

## 适用场景
- 企业遭受黑客攻击后的入侵调查
- 政府网站被篡改的溯源分析
- 数据泄露事件的安全调查
- 关键信息基础设施的网络安全事件响应
- 网络犯罪案件中的技术取证

## 输出成果
- 入侵分析报告（含攻击时间线、攻击路径图）
- 日志分析报告（含异常事件清单、攻击特征提取）
- 攻击链还原图（从入侵到数据窃取的完整链路）
- 恶意样本分析报告（含样本功能、行为描述）
- IoC 清单（恶意 IP、域名、文件哈希等指标）
- 安全加固建议

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及网络渗透攻击分析时触发
- 需要进行系统日志分析时触发
- 刑事案件中需要分析黑客攻击痕迹时触发
- 企业网络安全事件调查时触发
- 网络入侵检测与响应时触发
- 安全漏洞评估时触发
