# IoT取证 物联网终端

针对智能家居、车载系统、可穿戴设备、工业控制系统与无人机做数据提取与分析。

## 用途

IoT 设备的证据藏在固件、日志和云端同步记录里，形态和普通电脑完全不同。这个技能解决「设备怎么接、数据存在哪、固件能说明什么」。

三条准则：

1. 先摸清架构。设备型号、固件版本、通信方式决定提取路径。
2. 本地与云端双取。设备本地数据常被覆盖，云端同步记录往往是更完整的来源。
3. 固件不轻跑。固件分析在隔离环境做，不在取证主机直接执行。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 智能家居 | 门锁、摄像头、音箱、传感器的记录与联动日志 |
| 车载系统 | 车载单元、行车记录、导航与连接记录 |
| 可穿戴设备 | 运动、心率、睡眠、定位类数据 |
| 工业控制系统 | PLC、SCADA 的日志、配置与攻击痕迹 |
| 无人机 | 飞行日志、轨迹、限飞区域记录 |
| 通用分析 | 固件提取、通信协议、配套 APP 与云平台数据 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：交通事故车载数据提取、入室盗窃智能门锁与摄像头取证、工控系统被攻击调查、无人机违规飞行追踪、非法监控设备调查。

## 能力边界

1. 仅用于合法授权范围内的设备取证；
2. 不提供破解设备、绕过厂商保护的手段；
3. 厂商私有协议无法解析时，明确标注覆盖范围。
