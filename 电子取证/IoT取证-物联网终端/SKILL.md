# 技能名称：IoT设备取证

## 技能概述
对物联网（IoT）设备进行数据提取和分析，包括智能摄像头、智能音箱、智能手表、车载系统、智能家居设备、工业控制系统等。随着 IoT 设备的普及，相关取证需求日益增长。

---

## 核心能力

### 1. 智能家居设备取证
- **智能摄像头**：
  - 提取录像存储（SD 卡、云端）
  - 分析摄像头配置（IP、端口、WiFi 信息）
  - 提取用户访问记录和共享记录
  - 检测摄像头是否被非法接入（如被黑客控制）
- **智能音箱**：
  - 提取语音录音记录
  - 分析语音助手交互记录（查询历史、指令记录）
  - 提取设备关联的账号和 WiFi 信息
  - 恢复被删除的录音
- **智能门锁**：
  - 提取开锁记录（指纹、密码、钥匙、APP）
  - 分析门锁操作时间线
  - 提取用户管理记录（添加/删除用户）
- **智能电视/机顶盒**：
  - 提取观看记录、搜索记录
  - 分析安装的 APP 和使用记录
  - 提取 USB 存储设备访问记录

### 2. 车载系统取证
- **行车记录仪**：
  - 提取录像文件（含 GPS 轨迹、时间戳）
  - 分析碰撞/紧急录像事件
  - 提取车速、加速度等传感器数据
- **车载信息娱乐系统**：
  - 提取导航历史记录
  - 分析蓝牙连接记录（已配对手机）
  - 提取 USB 设备连接记录
  - 分析通话记录（通过车载蓝牙）
- **EDR（事件数据记录器）**：
  - 提取碰撞前后的车辆状态数据
  - 分析车速、刹车、方向盘转角等数据
  - 重建事故发生过程
- **T-Box（车载通信终端）**：
  - 提取车辆定位轨迹
  - 分析远程控制记录
  - 提取 CAN 总线数据

### 3. 可穿戴设备取证
- **智能手表/手环**：
  - 提取运动轨迹（GPS 记录）
  - 提取心率、睡眠等健康数据
  - 分析通知记录（来电、短信、APP 通知）
  - 提取蓝牙配对记录
- **智能眼镜**：
  - 提取拍摄的照片和视频
  - 分析录制时间线

### 4. 工业控制系统（ICS）取证
- **PLC（可编程逻辑控制器）**：
  - 提取 PLC 程序和配置
  - 分析逻辑修改记录
  - 检测异常的控制指令
- **SCADA 系统**：
  - 分析操作员操作记录
  - 提取传感器历史数据
  - 分析报警记录和响应
- **工业网络分析**：
  - 分析工业协议通信（Modbus、OPC、DNP3）
  - 检测异常的指令序列
  - 识别未授权的设备接入

### 5. 无人机取证
- **飞行日志提取**：提取飞行轨迹、高度、速度、电池状态。
- **照片/视频提取**：提取无人机拍摄的照片和视频，含 GPS 坐标。
- **遥控器分析**：分析遥控器中的飞行记录和配置。
- **云平台数据**：提取无人机云平台（如 DJI 云平台）上的飞行记录。

### 6. IoT 设备通用分析
- **固件提取与分析**：
  - 提取设备固件
  - 分析固件中的文件系统和配置
  - 检测固件中的后门和漏洞
- **网络通信分析**：
  - 分析 IoT 设备的网络通信行为
  - 识别与云平台的通信协议
  - 检测异常的数据外传
- **WiFi 信息提取**：
  - 提取设备连接过的 WiFi 网络信息
  - 分析 WiFi 连接历史

---

## 适用场景
- 交通事故中车载设备数据的提取与分析
- 入室盗窃案件中智能门锁/摄像头数据的取证
- 工业控制系统被攻击的安全事件调查
- 无人机违规飞行的追踪与取证
- 利用 IoT 设备进行的非法监控调查

## 输出成果
- IoT 设备数据提取报告（含设备信息、提取方式、数据量）
- 车辆轨迹分析报告（含轨迹地图、速度曲线）
- 飞行日志分析报告（含飞行轨迹、高度图）
- 工控系统安全分析报告
- 固件分析报告

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及物联网设备取证时触发
- 需要从IoT设备中提取数据时触发
- 刑事案件中需要分析智能设备数据时触发
- 企业IoT设备安全调查时触发
- 智能家居设备数据取证时触发
- IoT设备被入侵分析时触发
