## 分类原则

1. 一个技能包整体入库，不拆成多个目录。能力板块写在技能名后缀与该技能的 `README.md` 里。
2. 按取证流程顺序排列：工具底座、采集固定、对象提取、分析研判、对抗与恢复、合规出证。
3. 技能名后缀要能自解释，看到 `内存取证-易失数据` 就知道这个包覆盖哪一块，不用点进去猜。

## 收录底线

1. 仅用于合法授权范围内的取证工作，技能内明确标注授权前提；
2. 不收录未授权入侵、破解他人设备的方法；
3. 技术结论与司法认定分开，技能只提供技术判据；
4. 不收录具体在办案件的证据材料。
