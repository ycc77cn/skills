# 云环境取证 云主机对象

针对公有云、私有云与混合云环境做证据提取，覆盖云主机、容器、云服务日志、SaaS 数据与身份权限。

## 用途

云上证据不在本地磁盘，得按云平台的调用方式取。这个技能解决「数据在哪、怎么调、权限够不够、日志能说明什么」。

三条准则：

1. 先定位再采集。明确数据落在哪个区域、哪个服务、哪个存储桶，避免无效调取。
2. 日志即证据。云平台的操作日志与 API 审计记录是主要证据来源，优先保全。
3. 权限最小化。调取只用必要权限，全程记录调取账号与时间。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 云平台数据采集 | 云主机镜像、云盘、对象存储、快照与备份 |
| 容器与编排 | 容器镜像、运行时数据、编排平台配置与事件 |
| 云服务日志 | 操作审计、访问日志、网络日志、安全告警 |
| SaaS 服务取证 | 在线文档、邮件、协作平台的租户数据 |
| 身份与访问管理 | 账号、角色、策略、密钥、登录记录 |
| 多云与混合云 | 跨平台证据归集与时间对齐 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：云上数据泄露调查、云服务器入侵响应、云上非法站点取证、利用云服务的犯罪活动调查、云环境合规审计。

## 能力边界

1. 仅用于合法授权范围内的取证，需云租户或平台方配合；
2. 不提供越权调取他人云资源的方法；
3. 数据留存周期受平台策略限制，超期数据无法回溯时明确说明。
