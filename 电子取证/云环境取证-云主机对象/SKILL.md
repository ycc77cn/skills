# 技能名称：云环境取证

## 技能概述
对云计算平台（如阿里云、腾讯云、AWS、Azure）和云服务（SaaS、PaaS）中的数据进行取证分析，包括虚拟机、容器、云存储、云数据库等。随着越来越多企业和个人将数据迁移到云端，云取证已成为电子取证的重要领域。

---

## 核心能力

### 1. 云平台数据采集
- **虚拟机取证**：
  - 对云虚拟机进行在线或离线镜像
  - 提取虚拟机磁盘快照（云盘快照）
  - 分析虚拟机配置变更历史
  - 提取虚拟机控制台日志和系统日志
- **云存储取证**：
  - 提取对象存储（OSS/S3）中的文件和元数据
  - 分析文件上传/下载/删除记录
  - 恢复已删除的对象（在保留期内）
  - 分析存储桶的访问权限配置
- **云数据库取证**：
  - 提取云数据库（RDS）的全量备份和增量日志
  - 分析数据库操作审计日志
  - 恢复被删除的表和数据
  - 分析慢查询和异常查询

### 2. 容器与编排取证
- **Docker 容器取证**：
  - 提取容器镜像层（image layers）
  - 分析容器运行日志
  - 提取容器内的文件系统
  - 分析容器网络配置和通信记录
  - 恢复已停止/删除的容器数据
- **Kubernetes 取证**：
  - 提取 Pod 日志和事件记录
  - 分析集群配置变更历史
  - 提取 ConfigMap 和 Secret 数据
  - 分析服务间通信和访问控制策略
  - 审计 RBAC 权限配置

### 3. 云服务日志分析
- **操作审计日志**：
  - 云平台 API 调用记录（谁在什么时间做了什么操作）
  - 资源变更记录（创建、修改、删除虚拟机、数据库等）
  - 登录认证日志（成功/失败的登录尝试）
- **网络日志**：
  - VPC 流日志（虚拟网络中的流量记录）
  - 负载均衡访问日志
  - CDN 访问日志
  - NAT 网关日志
- **安全日志**：
  - 云安全中心告警日志
  - WAF（Web 应用防火墙）日志
  - DDoS 防护日志
  - 异常登录检测日志

### 4. SaaS 服务取证
- **办公协作平台**：
  - 钉钉/企业微信/飞书：聊天记录、文件传输、审批记录
  - 腾讯文档/石墨文档：文档编辑历史、协作记录
  - 企业邮箱：邮件内容、附件、收发记录
- **云盘取证**：
  - 百度网盘/阿里云盘/OneDrive：文件列表、分享记录、同步日志
  - 文件版本历史和删除恢复
- **代码托管平台**：
  - GitHub/GitLab/Gitee：代码提交历史、分支操作、Issue 记录
  - 代码泄露检测

### 5. 身份与访问管理
- **账号分析**：分析云平台账号的创建、权限变更、登录行为。
- **API 密钥审计**：审查 API 密钥的使用记录和权限范围。
- **跨账号访问**：分析不同云账号之间的访问关系。
- **临时凭证分析**：审查 STS 临时凭证的使用情况。

### 6. 多云与混合云取证
- **多云环境**：同时分析多个云平台的数据，统一视图。
- **混合云取证**：分析云上和本地数据中心之间的数据交互。
- **云迁移痕迹**：追踪数据从本地迁移到云端的过程和痕迹。

---

## 适用场景
- 企业云上数据泄露事件调查
- 云服务器被入侵的安全事件响应
- 云上非法网站的取证调查
- 利用云服务进行的犯罪活动调查
- 企业云环境的安全合规审计

## 输出成果
- 云环境取证报告（含平台信息、采集范围、数据量）
- 虚拟机/容器分析报告
- 云服务日志分析报告（含异常事件清单）
- API 调用审计报告
- 权限配置审查报告
- 数据流转分析报告

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及云平台数据取证时触发
- 需要从云服务中提取证据时触发
- 刑事案件中需要分析云存储数据时触发
- 企业云环境安全调查时触发
- 云服务数据泄露分析时触发
- 云平台日志分析时触发
