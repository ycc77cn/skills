# 内存取证 易失数据

对运行中的内存做采集与分析，提取进程、网络连接、凭据、密钥等易失数据，拿到磁盘上看不到的实时状态。

## 用途

关机就没了的东西，只能在内存里找。这个技能覆盖从采集到分析的完整链路。

三条准则：

1. 优先采集。内存数据随断电消失，能采就先采，别先折腾磁盘。
2. 交叉验证。进程列表、网络连接、注册表三处对照，单点结论不下判断。
3. 哈希留证。采集过程全程校验，保证镜像可用、可复现。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 内存镜像采集 | 在线采集、休眠文件、崩溃转储、页面文件四类来源 |
| 进程分析 | 进程列表与树、隐藏进程检测、注入检测、DLL 与命令行 |
| 网络连接分析 | 活动连接、监听端口、历史连接、套接字对象、DNS 缓存 |
| 密码与密钥提取 | 明文凭据、哈希、磁盘加密密钥、证书私钥、浏览器凭据 |
| 恶意代码检测 | Rootkit、Shellcode、恶意驱动、挖矿程序、C2 配置 |
| 系统信息 | 注册表、环境变量、用户会话、剪贴板、未保存文档 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：嫌疑人关机前紧急采集、运行中恶意软件与 Rootkit 检测、加密密钥提取、隐藏进程与连接发现、未保存文档恢复。

## 能力边界

1. 仅用于合法授权范围内的取证；
2. 采集需在目标机可控前提下进行，不提供远程未授权采集手段；
3. 内存镜像解析依赖符号表，版本不匹配时结论需标注置信度。
