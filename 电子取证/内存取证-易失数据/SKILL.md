# 技能名称：内存取证

## 技能概述
对计算机运行时的内存（RAM）进行采集和分析，提取易失性数据（如进程、网络连接、密码、密钥、加密信息等）。内存取证能够获取磁盘取证无法发现的实时运行状态信息，是电子取证中不可或缺的关键环节。

---

## 核心能力

### 1. 内存镜像采集
- **在线采集**：在系统运行状态下采集内存快照，使用专用工具（如 WinPmem、LiME、FTK Imager）。
- **休眠文件提取**：从 Windows 的 hiberfil.sys 或 macOS 的 sleepimage 中提取内存数据。
- **内存转储分析**：分析系统崩溃产生的内存转储文件（BSOD dump）。
- **页面文件提取**：从 Windows 的 pagefile.sys 中提取被换出到磁盘的内存数据。
- **防篡改采集**：采集过程中使用哈希校验确保内存镜像完整性。

### 2. 进程分析
- **进程列表**：列出内存中所有正在运行和已终止的进程。
- **进程树**：构建进程父子关系树，识别可疑的进程链。
- **隐藏进程检测**：通过交叉比对（DKOM 检测）发现被 Rootkit 隐藏的进程。
- **进程注入检测**：识别被注入恶意代码的正常进程。
- **DLL 分析**：列出每个进程加载的 DLL 模块，识别可疑的注入 DLL。
- **命令行参数**：提取进程启动时的完整命令行参数。

### 3. 网络连接分析
- **活动连接**：提取当前所有 TCP/UDP 网络连接。
- **监听端口**：识别系统开放的端口和对应的服务。
- **历史连接**：从内存中恢复已关闭的网络连接记录。
- **网络对象**：提取网络套接字（socket）的详细信息。
- **DNS 缓存**：提取系统 DNS 缓存中的域名解析记录。

### 4. 密码与密钥提取
- **明文密码**：从内存中提取应用程序保存的明文密码。
- **密码哈希**：提取 Windows NTLM 哈希、Linux shadow 密码哈希。
- **加密密钥**：提取 BitLocker、VeraCrypt 等加密软件的密钥。
- **证书和私钥**：提取存储在内存中的 SSL/TLS 证书和私钥。
- **WiFi 密码**：提取已连接 WiFi 网络的密码。
- **浏览器凭据**：提取浏览器中保存的网站密码、Cookie、Session。
- **SSH 密钥**：提取 SSH 客户端密钥和已知主机记录。

### 5. 恶意代码检测
- **Rootkit 检测**：通过内存特征检测内核级和用户级 Rootkit。
- **Shellcode 提取**：从进程内存中提取注入的 Shellcode。
- **恶意驱动检测**：识别加载的恶意内核驱动。
- **挖矿程序检测**：识别在内存中运行的加密货币挖矿程序。
- **C2 通信特征**：从内存中提取 C2 服务器的地址和通信配置。

### 6. 注册表与系统信息
- **注册表提取**：从内存中提取注册表信息（包括已删除的注册表键值）。
- **环境变量**：提取系统环境变量。
- **用户会话**：提取当前登录用户和会话信息。
- **剪贴板内容**：提取当前剪贴板中的数据。
- **未保存文档**：尝试从内存中恢复未保存的文档内容。

---

## 适用场景
- 嫌疑人关机前紧急采集内存数据
- 检测运行中的恶意软件和 Rootkit
- 提取加密密钥以解密加密磁盘或文件
- 发现被隐藏的恶意进程和网络连接
- 恢复未保存的文档和浏览器数据

## 输出成果
- 内存采集记录（含采集时间、工具、哈希校验）
- 进程分析报告（含进程树、可疑进程标注）
- 网络连接报告（含活动连接、历史连接、DNS 缓存）
- 密码/密钥提取报告（含提取的凭据清单）
- 恶意代码检测报告（含检测结果、样本特征）
- 系统信息摘要

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及内存数据提取与分析时触发
- 需要进行内存镜像分析时触发
- 刑事案件中需要分析运行中的程序数据时触发
- 企业安全事件响应时触发
- 恶意软件分析时触发
- 系统崩溃分析时触发
