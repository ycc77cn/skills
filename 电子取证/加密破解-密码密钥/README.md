# 加密破解 密码密钥

对加密文件、加密磁盘、加密通信与密码保护对象做密码恢复与解密，还原受保护的数据内容。

## 用途

拿到加密容器不等于拿到证据。这个技能解决「密码怎么找回、密钥从哪来、解不开时怎么办」。

三条准则：

1. 先找密钥再暴力。内存、配置文件、备份里常留密钥，穷举是最后手段。
2. 授权前提明确。所有破解动作需有合法授权文件对应。
3. 过程完整记录。方法、字典、耗时、结果全部留档，便于复现与质证。

| 板块 | 内容 |

| 密码恢复 | 字典、规则、掩码、碰撞策略与适用条件 |

| 磁盘加密破解 | 全盘加密的密钥定位与恢复条件 |

| 网络协议密码 | 通信加密的密钥来源与解密前提 |
| 哈希识别与破解 | 哈希类型判定、离线破解与在线验证 |
| 密码分析与评估 | 强度评估、策略建议、剩余空间判断 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：涉案加密设备解锁、加密文档与压缩包破解、入侵中获取的哈希破解、企业弱密码审计、授权范围内的加密通信解密。

## 能力边界

1. 仅在有明确合法授权的场景使用；
2. 不提供未授权破解他人设备或数据的方法；
3. 强加密与无密钥场景无法破解时，如实说明并给出替代路径。
