# 技能名称：加密与密码破解

## 技能概述
对加密文件、加密磁盘、加密通信、密码保护文件等进行解密和密码恢复，获取被加密保护的数据内容。密码破解是电子取证中打开证据"最后一道门"的关键技术。

---

## 核心能力

### 1. 密码恢复技术
- **字典攻击**：
  - 使用常用密码字典（如 rockyou.txt、中文密码字典）
  - 支持自定义字典（基于案件信息生成的针对性字典）
  - 支持字典组合和变换（大小写、数字追加、符号替换）
- **暴力破解**：
  - 对所有可能的密码组合进行穷举
  - 支持自定义字符集和密码长度范围
  - 支持分布式破解（多 GPU 并行加速）
- **规则攻击**：
  - 基于已知密码模式生成变体（如将"password"变为"Password1!"）
  - 支持自定义破解规则
  - 支持社会工程学规则（基于个人信息生成密码候选）
- **彩虹表攻击**：
  - 使用预计算的彩虹表快速破解
  - 支持多种哈希算法的彩虹表
- **掩码攻击**：
  - 在已知部分密码结构的情况下，对未知部分进行破解
  - 例如已知密码格式为"姓名+4位数字"，只对数字部分暴力破解

### 2. 文件密码破解
- **Office 文档**：破解 Word、Excel、PowerPoint 的打开密码和修改密码。
- **PDF 文件**：破解 PDF 的打开密码、权限密码、 owner 密码。
- **压缩文件**：破解 ZIP、RAR、7z 的加密密码。
- **数据库文件**：破解 SQLite、Access 等数据库的密码。
- **手机备份**：破解 iOS 备份密码、Android 备份密码。

### 3. 磁盘加密破解
- **BitLocker**：
  - 从内存中提取恢复密钥
  - 破解 BitLocker 密码或 PIN
  - 利用 TPM 信息进行破解
- **VeraCrypt / TrueCrypt**：
  - 破解容器密码
  - 利用隐藏卷特征检测
  - 从内存中提取密钥
- **FileVault（macOS）**：
  - 从内存或系统钥匙串中提取恢复密钥
  - 破解 FileVault 密码
- **LUKS（Linux）**：
  - 破解 LUKS 加密分区的密码
  - 从内存中提取密钥材料

### 4. 操作系统密码破解
- **Windows 密码**：
  - 提取 NTLM 哈希，离线破解
  - 利用 Pass-the-Hash 技术直接认证
  - 破解 Windows 本地账户和域账户密码
- **Linux 密码**：
  - 提取 /etc/shadow 中的密码哈希
  - 破解各种加密算法的哈希（MD5、SHA-256、SHA-512、bcrypt）
- **macOS 密码**：
  - 提取和破解 macOS 用户密码
  - 分析钥匙串（Keychain）中的密码

### 5. 网络协议密码破解
- **WiFi 密码**：
  - 破解 WPA/WPA2/WPA3 握手包
  - 支持 PMKID 攻击（无需等待握手）
  - 分析已保存的 WiFi 配置文件
- **浏览器保存的密码**：
  - 提取 Chrome、Firefox、Edge 等浏览器保存的密码
  - 解密浏览器密码存储（使用 DPAPI 或 NSS 库）
- **邮箱密码**：破解 Outlook、Thunderbird 等邮件客户端保存的密码。
- **FTP/SSH 密码**：破解 FTP 客户端和 SSH 客户端保存的密码。
- **VPN 密码**：分析 VPN 客户端配置文件中的密码。

### 6. 密码哈希识别与破解
- **哈希类型识别**：自动识别哈希的类型（MD5、SHA-1、SHA-256、bcrypt、NTLM 等）。
- **哈希破解**：
  - 支持 300+ 种哈希算法的破解
  - 支持多种破解模式（字典、暴力、规则、掩码）
  - GPU 加速破解（利用 NVIDIA/AMD GPU 加速）
- **哈希碰撞检测**：检测是否存在哈希碰撞。

### 7. 密码分析与评估
- **密码强度评估**：评估已破解密码的强度，判断是否存在弱密码。
- **密码策略分析**：分析系统的密码策略配置是否合理。
- **密码复用检测**：检测同一密码在不同系统中的复用情况。
- **密码模式分析**：分析用户设置密码的习惯和模式。

---

## 适用场景
- 涉案加密电脑/手机的解锁
- 加密文档和压缩包的密码破解
- 网络入侵中获取的密码哈希破解
- 企业安全审计中的弱密码检测
- 加密通信内容的解密（在合法授权下）

## 输出成果
- 密码破解报告（含破解方法、耗时、结果）
- 破解的密码清单（含对应账户/文件）
- 密码强度分析报告
- 未破解密码的后续建议（如增加字典、调整策略）
- 解密后的数据文件

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及加密数据破解时触发
- 需要进行密码分析时触发
- 刑事案件中需要解密证据时触发
- 企业安全事件中需要破解加密数据时触发
- 密码强度评估时触发
- 加密算法分析时触发
