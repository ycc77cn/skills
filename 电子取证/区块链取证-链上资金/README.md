# 区块链取证 链上资金

针对区块链与加密货币做链上交易分析、地址关联、资金追踪与智能合约解析，还原涉案资金流向。

## 用途

链上数据公开但难读。这个技能解决「钱从哪来、到哪去、地址背后是谁、跨链怎么接上」。

三条准则：

1. 交易哈希为准。所有结论必须落到具体交易哈希与区块高度，可复核。
2. 地址聚类。多地址归并成一个实体后，资金链路才说得清。
3. 跨链单独接。跨链桥、兑换、混币环节要单独标注断点，不硬拼链路。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 链上交易分析 | 交易明细、输入输出、手续费特征、批量归集识别 |
| 钱包地址关联 | 地址聚类、实体识别、交易所与混币服务标注 |
| 涉案资金追踪 | 资金流向图、层级结构、冻结与流向统计 |
| 智能合约分析 | 合约调用、代币流转、异常合约识别 |
| 跨链追踪 | 跨链桥与兑换环节的链路拼接与断点说明 |
| 威胁情报关联 | 地址与已知风险实体的比对 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：电信诈骗加密货币追踪、勒索赎金追踪、洗钱链路分析、暗网交易取证、非法集资涉币取证。

## 能力边界

1. 仅用于合法授权范围内的取证；
2. 地址背后的真实身份需结合链下证据，单靠链上数据不下身份结论；
3. 隐私币与混币服务可追踪性有限，结论需标注不确定性。
