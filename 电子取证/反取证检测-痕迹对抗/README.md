# 反取证检测 痕迹对抗

识别数据擦除、数据隐藏、时间戳篡改、日志清除、Rootkit 与沙箱逃逸等反取证手段。

## 用途

对方想抹痕迹时，抹的动作本身也会留痕。这个技能解决「有没有被抹、抹了什么、能不能还原」。

三条准则：

1. 抹除必留矛盾。擦除后的空区、日志断档、时间戳跳变都是可检出的证据。
2. 多源交叉。单点异常不足以下结论，文件系统、日志、注册表三处对照。
3. 还原要标推断。被删内容的重建结果属推断，必须标注方法与置信度。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：嫌疑人销毁证据案件、APT 攻击调查、内部人员掩盖痕迹调查、涉密数据泄露检测、证据完整性验证。

## 能力边界

1. 仅用于合法授权范围内的检测；
2. 不提供实施反取证的方法；
3. 检测结果为技术判据，最终认定需结合案件其他证据。
