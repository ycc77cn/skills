# 技能名称：反取证技术检测

## 技能概述
识别和检测嫌疑人使用的反取证技术（Anti-Forensics），发现被故意隐藏、伪装、销毁的数据和痕迹。反取证技术是犯罪分子试图逃避电子取证的常用手段，检测这些技术是完整取证的关键。

---

## 核心能力

### 1. 数据擦除痕迹检测
- **安全擦除检测**：
  - 检测是否使用了安全擦除工具（如 DBAN、Eraser、Cipher）
  - 分析磁盘的覆写模式和次数
  - 判断数据是否已被安全擦除且无法恢复
- **选择性删除检测**：
  - 检测特定文件或目录被定向删除的痕迹
  - 分析文件系统的 MFT 空闲区域，发现删除记录
  - 对比文件系统时间戳，发现异常的批量删除行为
- **擦除工具残留**：
  - 检测擦除工具的安装痕迹（程序文件、注册表项）
  - 分析擦除工具的使用日志
  - 检测擦除工具的下载记录

### 2. 数据隐藏检测
- **文件隐藏**：
  - 检测通过文件属性隐藏的文件（隐藏属性、系统属性）
  - 检测通过 NTFS 流（Alternate Data Streams）隐藏的数据
  - 检测通过扩展名伪装隐藏的文件（如将 .exe 改为 .jpg）
  - 检测隐藏分区和未分配空间中的数据
- **隐写术检测**：
  - 图像隐写检测（LSB 隐写、DCT 域隐写）
  - 音频隐写检测
  - 文档隐写检测（在文档元数据或空白区域隐藏数据）
  - PDF 隐写检测
- **卷影副本分析**：
  - 检测 Windows 卷影副本（VSS）中保存的历史数据
  - 从卷影副本中恢复被删除或修改的文件
- **加密容器检测**：
  - 检测 VeraCrypt、BitLocker、FileVault 等加密容器
  - 分析加密容器的头部特征
  - 检测 plausible deniability（合理否认）加密方案

### 3. 时间戳篡改检测
- **文件时间戳分析**：
  - 检测文件创建时间、修改时间、访问时间的一致性
  - 识别异常的时间戳（如未来时间、1970 年时间）
  - 对比 MFT 时间戳和文件系统日志，发现不一致
- **系统时间篡改**：
  - 检测系统时间被修改的痕迹
  - 分析事件日志中的时间跳跃
  - 对比不同日志源的时间戳一致性
- **时间反混淆**：
  - 通过多源时间戳交叉验证，还原真实时间线

### 4. 日志清除检测
- **Windows 日志清除**：
  - 检测 Windows 事件日志被清除的痕迹（日志间隙、事件 ID 1102）
  - 从日志备份或副本中恢复被清除的日志
  - 分析日志清除操作的时间和操作者
- **Linux 日志清除**：
  - 检测 /var/log 目录下日志文件被删除或清空的痕迹
  - 分析日志轮转配置是否被异常修改
  - 从 journalctl 持久化日志中恢复数据
- **应用日志清除**：
  - 检测 Web 服务器、数据库、中间件等应用日志被清除的痕迹
  - 分析日志文件的修改时间和大小变化

### 5. Rootkit 与反取证工具检测
- **内核级 Rootkit 检测**：
  - 通过内存取证检测内核级 hook（SSDT hook、IDT hook）
  - 检测 DKOM（直接内核对象操作）隐藏的进程和驱动
  - 检测文件系统过滤驱动隐藏的文件和注册表项
- **用户级 Rootkit 检测**：
  - 检测应用层 hook（IAT hook、inline hook）
  - 检测 DLL 注入和进程注入
  - 检测隐藏的服务和计划任务
- **反取证工具识别**：
  - 检测已知反取证工具的安装和使用痕迹
  - 识别自定义的反取证脚本和工具
  - 分析反取证工具的配置和操作记录

### 6. 虚拟化与沙箱逃逸检测
- **虚拟机检测**：
  - 检测恶意软件中的虚拟机检测代码
  - 分析恶意软件是否在虚拟环境中改变了行为
- **沙箱逃逸检测**：
  - 检测恶意软件的沙箱检测和逃逸技术
  - 分析恶意软件的延迟执行和环境检测逻辑

---

## 适用场景
- 嫌疑人试图销毁电子证据的案件
- 高级持续性威胁（APT）攻击调查
- 内部人员违规操作且试图掩盖痕迹的调查
- 涉密数据泄露事件中的反取证手段检测
- 复杂电子取证案件中证据完整性验证

## 输出成果
- 反取证技术检测报告（含检测到的技术类型、证据）
- 隐藏数据发现报告（含发现的隐藏文件、隐写数据）
- 时间戳篡改分析报告（含真实时间线还原）
- 日志清除检测报告（含清除时间、操作者、恢复数据）
- Rootkit 检测报告（含检测结果、隐藏对象清单）

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及反取证技术检测时触发
- 需要识别证据篡改痕迹时触发
- 刑事案件中怀疑证据被销毁时触发
- 企业安全事件中发现反取证行为时触发
- 数据完整性验证时触发
- 证据真实性鉴定时触发
