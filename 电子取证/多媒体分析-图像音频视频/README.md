# 多媒体分析 图像音频视频

对图像、视频、音频证据做检索、结构化分析、伪造检测与元数据提取。

## 用途

多媒体证据最容易被动过手脚。这个技能解决「这张图是不是原图、视频里有什么、录音有没有剪辑」。

三条准则：

1. 元数据先看。EXIF、编码参数、设备信息能直接判断来源与是否二次处理。
2. 篡改看痕迹。压缩残差、噪声分布、光照一致性、边缘接缝是主要判据。
3. 结论带置信度。伪造检测是概率判断，必须标注方法与置信度，不下绝对结论。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：诈骗案件图片视频固定、监控录像中嫌疑人与车辆定位、合同票据真伪鉴定、深伪视频识别、录音真实性鉴定。

## 能力边界

1. 仅用于合法授权范围内的证据分析；
2. 伪造检测结果为技术判断，不替代司法鉴定结论；
3. 低分辨率与强压缩素材的检测可靠性下降，需明确标注。
