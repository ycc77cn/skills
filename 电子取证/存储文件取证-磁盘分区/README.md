# 存储文件取证 磁盘分区

针对存储介质上的文件做定向提取与解析，覆盖数据库文件、表格、结构化数据、日志、备份与专用格式，并做文件元数据分析。

## 用途

拿到镜像之后，真正要找的是文件里的内容。这个技能解决「文件是什么格式、里面有什么、有没有被删掉或藏起来」三个问题。

三条准则：

1. 按格式定方法。不同文件类型走不同的解析路径，不套用同一套流程。
2. 先看元数据再看内容。时间戳、哈希、属性、ADS 往往比正文更能说明问题。
3. 删掉的也要找。未分配空间、隐藏工作表、备用数据流都要纳入检查范围。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 数据库文件 | SQLite、Access、db 类文件的表结构与记录提取 |
| 表格文件 | Excel 多工作表、隐藏行列表、公式与外部链接 |
| 结构化数据 | JSON、XML、CSV、配置文件的结构还原 |
| 日志文件 | 系统与业务日志的时间序列提取与异常定位 |
| 备份文件 | 压缩包、备份集中历史版本数据的提取 |
| 专用格式 | 应用私有格式的识别与字段还原 |
| 文件元数据 | 时间戳、哈希、属性、ADS、嵌入对象分析 |

## 内部结构

```text
存储文件取证-磁盘分区/
├── SKILL.md        # 主文件：七类文件取证方法与输出要求
└── README.md       # 本文件
```

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：手机 APP 数据库提取、涉案表格财务数据提取、服务器配置审计、压缩包隐藏证据提取、备份历史数据恢复。

## 能力边界

1. 只做读取与解析，不改动原始文件；
2. 私有格式无法完整解析时，明确标注解析范围与不确定项；
3. 加密文件转交加密破解类技能处理。
