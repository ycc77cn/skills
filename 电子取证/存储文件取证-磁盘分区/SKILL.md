# 技能名称：存储文件取证

## 技能概述
对各类用于存储数据的文件格式进行取证分析，包括数据库文件（.db、.sqlite、.mdb）、表格文件（.xlsx、.xls、.csv）、结构化数据文件（.json、.xml）、配置文件（.ini、.yaml、.conf）等。这些文件广泛存在于电脑、手机、服务器和各类应用中，是电子取证中最常接触的数据载体。

---

## 核心能力

### 1. 数据库文件取证
- **SQLite 数据库（.db、.sqlite、.sqlite3）**：
  - 直接打开并解析 SQLite 数据库文件
  - 提取所有表的结构和数据
  - 从 WAL（Write-Ahead Log）文件中恢复已删除/修改的记录
  - 从 free pages 中恢复已删除的数据
  - 分析数据库的 journal 文件
  - 常见应用场景：手机 APP 数据、浏览器历史、聊天记录缓存
- **Access 数据库（.mdb、.accdb）**：
  - 提取表结构和数据
  - 恢复已删除的记录
  - 分析查询和宏
- **Berkeley DB（.db）**：
  - 解析键值对存储的数据
  - 提取结构化记录
- **LevelDB / RocksDB**：
  - 解析 LSM-Tree 存储引擎的数据
  - 提取键值对数据
  - 常见应用场景：Chrome 浏览器数据、部分 APP 缓存
- **其他数据库格式**：
  - Parquet、ORC 等列式存储格式
  - DBF（dBase/FoxPro）
  - Firebird（.fdb）

### 2. 表格文件取证
- **Excel 文件（.xlsx、.xls）**：
  - 提取所有工作表的数据
  - 分析单元格格式、公式、条件格式
  - 提取隐藏的工作表和隐藏的行/列
  - 恢复已删除的工作表（从 ZIP 结构中提取残留文件）
  - 分析宏代码（VBA）
  - 提取批注、数据验证规则
  - 分析修订记录和版本历史
  - 提取嵌入的对象（OLE 对象、图片）
- **CSV 文件（.csv、.tsv）**：
  - 自动检测编码（UTF-8、GBK、GB2312 等）
  - 自动检测分隔符（逗号、制表符、分号等）
  - 处理引号嵌套和特殊字符转义
  - 提取列名和数据类型
- **WPS 表格（.et）**：
  - 提取工作表数据
  - 分析公式和格式

### 3. 结构化数据文件取证
- **JSON 文件（.json）**：
  - 解析并格式化 JSON 数据
  - 处理嵌套结构和大文件
  - 提取关键字段
  - 常见应用场景：APP 配置文件、API 响应缓存、浏览器书签
- **XML 文件（.xml）**：
  - 解析 XML 结构和内容
  - 提取元素和属性
  - 分析 XSD Schema 定义
  - 常见应用场景：Android 布局文件、Office 文档内部结构、配置文件
- **INI / CFG / CONF 文件**：
  - 解析键值对配置
  - 提取服务器配置、应用配置
  - 分析配置变更（对比默认配置）
- **YAML / TOML 文件**：
  - 解析现代配置文件格式
  - 提取 Docker Compose、CI/CD 配置等

### 4. 日志文件取证
- **文本日志（.log）**：
  - 自动识别日志格式（Apache/Nginx、系统日志、应用日志）
  - 按时间范围、关键词、日志级别筛选
  - 统计错误、警告等异常日志
  - 提取 IP 地址、URL、用户代理等关键字段
- **二进制日志**：
  - 解析 Windows 事件日志（.evtx）
  - 解析 Linux journal 日志
  - 解析 IIS 日志
- **结构化日志**：
  - 解析 JSON 格式日志
  - 解析 CSV 格式日志

### 5. 备份文件取证
- **压缩包分析（.zip、.rar、.7z、.tar.gz）**：
  - 列出压缩包内的文件清单
  - 提取文件内容和元数据（压缩时间、文件大小、CRC）
  - 破解压缩包密码（字典攻击、暴力破解）
  - 检测加密压缩包中的文件类型
  - 分析分卷压缩包
- **磁盘镜像中的文件**：
  - 从磁盘镜像中挂载和提取特定文件
  - 分析 VMDK、VHD、QCOW2 等虚拟磁盘格式
- **系统备份文件**：
  - 分析 Windows 备份（.bkf、.vhdx）
  - 分析 macOS Time Machine 备份
  - 分析手机备份文件（iTunes 备份、ADB 备份）

### 6. 专用格式文件取证
- **PDF 文件（.pdf）**：
  - 提取文本内容和嵌入图片
  - 分析 PDF 元数据（作者、创建时间、修改时间）
  - 检测 PDF 中的嵌入文件（附件）
  - 分析 PDF 表单数据
  - 恢复已删除的 PDF 页面
- **Office 文档（.docx、.pptx）**：
  - 从 DOCX/PPTX 的 XML 结构中提取隐藏数据
  - 分析文档属性和修订记录
  - 提取嵌入对象和 OLE 数据
  - 恢复自动保存的临时文件
- **缓存文件**：
  - 浏览器缓存（Chrome Cache、Firefox Cache）
  - 缩略图缓存（Thumbs.db、Windows 缩略图缓存）
  - DNS 缓存
  - 图标缓存

### 7. 文件元数据分析
- **文件头分析**：通过文件头魔数识别文件真实类型（防止扩展名伪造）。
- **时间戳分析**：分析文件的创建时间、修改时间、访问时间（MACE）。
- **文件哈希**：计算文件哈希值，用于唯一标识和完整性校验。
- **文件属性**：分析文件属性（只读、隐藏、系统、加密）。
- **NTFS 备用数据流**：检测和提取 NTFS ADS 中隐藏的数据。

---

## 适用场景
- 手机 APP 数据库文件的提取和分析
- 涉案 Excel 表格中的财务数据提取
- 服务器配置文件的安全审计
- 压缩包中隐藏证据的提取
- 备份文件中历史数据的恢复
- 浏览器缓存中已删除内容的恢复

## 输出成果
- 存储文件分析报告（含文件类型、大小、内容摘要）
- 提取的数据文件（CSV/Excel/JSON 格式）
- 已删除数据恢复清单
- 文件元数据报告（含时间戳、哈希、属性信息）
- 隐藏数据发现报告（含隐藏工作表、ADS 数据、嵌入对象）
- 密码破解结果（如适用）

- 任何司法与取证工作都应该被触发

- 需要分析文件系统数据时触发

- 企业存储设备安全调查时触发
- 文件系统损坏分析时触发
- 存储介质数据恢复时触发
