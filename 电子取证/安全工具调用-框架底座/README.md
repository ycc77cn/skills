# 安全工具调用 框架底座

把取证全流程用到的各类工具统一成一套调用规范，负责调度、参数约束、输出解析与全程留痕。

## 用途

解决取证工具多、命令杂、参数记不住的问题。用户用自然语言下指令，技能负责判定该调哪个工具、参数怎么给、输出怎么解析、日志怎么留。

两条准则：

1. 只调度、不替代。工具本身的行为不改造，技能只负责选、调、记。
2. 全程留痕。每一次调用都记录完整命令、参数、执行时间与结果，供后续复盘和证据链使用。

| AI 调用策略 | 多工具串接顺序、失败回退、结果交叉验证 |

## 内部结构

```text
安全工具调用-框架底座/
├── SKILL.md        # 主文件：八类工具调用规范、调度策略、留痕要求
└── README.md       # 本文件
```

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：需要串联多个取证工具、需要把自然语言指令转成具体命令、需要构建自动化取证工具链。

## 能力边界

1. 只做调用编排，不内置工具本体，工具需自行准备；
2. 不提供绕过授权或规避审计的调用方式；
3. 涉及破坏性参数的操作必须先确认，不做默认执行。
