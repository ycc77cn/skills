# 技能名称：安全工具调用框架

## 技能概述
定义 AI 在电子取证过程中调用各类专业安全工具和取证工具的标准方式。AI 根据取证任务需求，自动选择合适的工具、构建正确的命令参数、执行操作并解析输出结果，实现取证流程的自动化和智能化。

---

## 核心能力

### 1. 磁盘取证工具调用
- **FTK Imager**：
  - 创建磁盘/分区镜像（E01、DD 格式）
  - 预览文件系统内容
  - 提取文件和文件夹
  - 哈希计算和验证
- **Autopsy / The Sleuth Kit**：
  - 分析磁盘镜像的文件系统
  - 时间线分析
  - 关键词搜索
  - 已删除文件恢复
  - 哈希过滤（已知文件过滤）
  - Web 浏览记录提取
  - 电子邮件提取
- **X-Ways Forensics**：
  - 高级文件系统分析
  - 搜索和过滤
  - 数据恢复
  - 报告生成
- **Plaso / Log2Timeline**：
  - 从多个数据源提取时间线数据
  - 生成统一的时间线
  - 支持超级时间线分析

### 2. 内存取证工具调用
- **Volatility 3**：
  - 进程列表（pslist、psscan）
  - 网络连接（netscan、netstat）
  - 注册表提取（hivelist、printkey）
  - 密码哈希提取（hashdump）
  - 恶意代码检测（malfind）
  - DLL 列表（dlllist）
  - 命令行历史（cmdscan、consoles）
- **Rekall**：
  - 内存镜像分析
  - 进程和内存映射分析
  - 网络连接分析

### 3. 网络分析工具调用
- **Wireshark / tshark**：
  - 流量包捕获和过滤
  - 协议深度解析
  - 会话重建
  - 文件自动提取
  - 统计分析
- **NetworkMiner**：
  - 网络取证分析
  - 主机信息提取
  - 图片和文件提取
  - 参数嗅探
- **Zeek（Bro）**：
  - 网络流量分析
  - 协议解析
  - 日志生成
- **tcpdump**：
  - 命令行流量捕获
  - BPF 过滤器应用

### 4. 漏洞扫描与渗透工具调用
- **Nmap**：
  - 主机发现
  - 端口扫描
  - 服务版本检测
  - 操作系统识别
  - NSE 脚本扫描（漏洞检测）
- **Nessus / OpenVAS**：
  - 漏洞扫描
  - 配置审计
  - 合规性检查
- **Burp Suite**：
  - Web 应用渗透测试
  - 请求/响应拦截和修改
  - 漏洞扫描（SQL 注入、XSS 等）
  - 爬虫和内容发现
- **Metasploit Framework**：
  - 漏洞利用验证
  - 后渗透操作
  - 模块化攻击测试

### 5. 移动设备取证工具调用
- **Cellebrite UFED**：
  - 手机数据逻辑/物理提取
  - APP 数据解析
  - 报告生成
- **Magnet AXIOM**：
  - 手机和电脑数据提取
  - AI 驱动的数据分析
  - 可视化展示
- **MOBILedit Forensic**：
  - 手机数据提取
  - 通讯录、短信、通话记录分析
- **ADB / Fastboot（Android）**：
  - 通过 ADB 提取 Android 数据
  - 安装取证工具到设备
  - 屏幕截图和录屏
- **irecovery / libimobiledevice（iOS）**：
  - iOS 设备信息提取
  - 备份提取和管理

### 6. 密码破解工具调用
- **Hashcat**：
  - GPU 加速密码破解
  - 支持 300+ 种哈希算法
  - 字典攻击、暴力破解、规则攻击、掩码攻击
  - 分布式破解
- **John the Ripper**：
  - 离线密码破解
  - 多种哈希格式支持
  - 自定义规则
- **fcrackzip / rar2john / zip2john**：
  - 压缩包密码破解
- **SAMdump2 / mimikatz**：
  - Windows 密码哈希提取

### 7. 数据恢复工具调用
- **TestDisk / PhotoRec**：
  - 分区恢复
  - 文件恢复（按签名搜索）
- **R-Studio / EaseUS**：
  - RAID 恢复
  - 深度扫描恢复
- **Foremost / Scalpel**：
  - 基于文件头的 carving 恢复
  - 自定义文件签名

### 8. AI 工具调用策略
- **工具自动选择**：根据任务类型自动选择最合适的工具组合。
- **参数自动构建**：根据输入数据自动构建正确的命令参数。
- **结果自动解析**：自动解析工具输出，提取关键信息。
- **错误处理**：工具执行失败时自动诊断原因并尝试替代方案。
- **命令审计**：记录所有工具调用的完整命令和输出，用于证据链追溯。
- **并行执行**：对独立的任务并行调用多个工具，提高效率。

## 适用场景
- AI 自动化取证流程中的工具调度
- 批量证据分析中的工具链自动化
- 取证人员通过自然语言指挥 AI 执行工具操作
- 复杂取证任务中多工具协同分析
- 取证培训中的工具使用演示

## 输出成果
- 工具调用日志（含完整命令、参数、执行时间）
- 工具输出解析报告（含关键发现摘要）
- 工具调用链路图（含工具间的数据流转关系）
- 错误和异常记录
- 自动化取证流程报告

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及安全工具调用时触发
- 需要集成多个取证工具时触发
- 刑事案件中需要使用多种工具分析证据时触发
- 企业安全自动化测试时触发
- 安全工具链构建时触发
- 工具调用流程优化时触发
