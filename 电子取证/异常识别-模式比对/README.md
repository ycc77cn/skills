# 异常识别 模式比对

对资金流水、网络日志、用户行为做异常检测、聚类分类、关联规则挖掘与风险评分。

## 用途

数据量太大，靠人眼看不出问题。这个技能解决「哪条不对劲、哪些属于一伙、风险多高」。

三条准则：

1. 先定基线再谈异常。没有正常样本的「异常」是空话，先建立行为基线。
2. 多维度交叉。单一指标异常不足以定性，资金、时间、关系三个维度对照后再判断。
3. 评分可解释。风险评分必须给出构成因子，不做黑箱结论。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 资金链分析 | 流向图、层级结构、异常交易与归集识别 |
| 网络行为异常 | 异常事件清单、威胁等级、时间线定位 |
| 聚类与分类 | 实体分组、群体特征描述、同类归并 |
| 关联规则挖掘 | 共现关系、频繁模式、隐含关联 |
| 风险评分与预警 | 实体现评分、风险因子说明、告警与处置建议 |

## 内部结构

异常识别-模式比对/

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：洗钱资金链追踪、电信诈骗涉案账户识别、企业数据泄露排查、网络入侵行为分析、金融风控异常交易监测。

## 能力边界

1. 仅用于合法授权范围内的分析；
2. 异常检测结果为线索，需人工核查后采信；
3. 样本量不足时不做模式结论。
