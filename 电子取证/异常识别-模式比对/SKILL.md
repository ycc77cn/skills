# 技能名称：异常与模式识别

## 技能概述
利用人工智能和数据分析技术，从资金流水、网络日志、用户行为等海量数据中自动识别异常模式、可疑行为和潜在犯罪线索，帮助快速缩小排查范围。

---

## 核心能力

### 1. 资金链分析
- **交易流水梳理**：自动整理银行流水、第三方支付记录、虚拟货币交易记录，生成统一格式的资金明细。
- **洗钱模式识别**：
  - 分散转入、集中转出（"蚂蚁搬家"式洗钱）
  - 集中转入、分散转出（"拆分"式洗钱）
  - 快速进出（资金在账户中短暂停留后转出）
  - 循环转账（资金在多个账户间反复流转）
  - 跨境转移（通过地下钱庄或虚拟货币跨境转移资金）
- **涉诈账户识别**：
  - 高频小额收款（典型的诈骗资金归集模式）
  - 深夜/凌晨异常交易
  - 新开户即大额交易
  - 交易对手高度分散
  - 与已知涉案账户有关联
- **资金流向可视化**：生成资金流向图，展示资金从来源到最终去向的完整链路。
- **层级分析**：自动识别资金转移的层级结构，定位资金归集层、中转层、取现层。

### 2. 网络行为异常检测
- **异地登录检测**：识别同一账号在短时间内从不同地理位置登录。
- **暴力破解检测**：发现对系统、邮箱、数据库的暴力破解尝试。
- **后门/木马检测**：识别异常的网络连接、未知进程、非常规端口通信。
- **数据外带检测**：监控大量数据向外部传输的行为（如大批量下载、上传到网盘）。
- **可疑 IP 识别**：关联威胁情报库，识别与恶意活动相关的 IP 地址。
- **流量加密异常**：检测异常的加密通信模式（如非标准端口上的加密流量、异常的证书使用）。
- **DNS 隧道检测**：识别通过 DNS 协议进行隐蔽数据传输的行为。

### 3. 聚类与分类分析
- **相似文件聚类**：将内容相似的文档自动分组（如多份相似的合同模板、批量生成的诈骗话术）。
- **行为聚类**：将行为模式相似的账号或设备分组（如使用相同工具的入侵行为）。
- **账号分类**：根据行为特征将账号分类（正常用户、可疑用户、恶意用户）。
- **异常值检测**：识别偏离正常模式的数据点（如异常大额交易、异常登录时间）。
- **时间序列异常**：检测时间维度上的异常变化（如流量突增、交易频率突变）。

### 4. 关联规则挖掘
- **频繁项集发现**：发现经常一起出现的物品、行为或特征组合。
- **序列模式挖掘**：发现行为之间的先后顺序规律（如"开户→小额测试→大额转账"）。
- **关联网络分析**：构建实体之间的多维关联网络，发现隐藏关系。

### 5. 风险评分与预警
- **综合风险评分**：结合资金、网络、行为等多维度数据，为每个实体计算风险评分。
- **实时预警**：对高风险事件实时告警（如大额异常转账、可疑登录）。
- **趋势预测**：基于历史数据预测可能的异常行为趋势。

## 适用场景
- 洗钱案件中的资金链追踪和模式分析
- 电信诈骗案件中的涉案账户识别和资金流向梳理
- 企业内部数据泄露事件的排查
- 网络入侵事件中的攻击行为分析
- 金融风控中的异常交易监测

## 输出成果
- 资金链分析报告（含流向图、层级结构、异常交易清单）
- 网络行为异常报告（含异常事件清单、威胁等级、时间线）
- 聚类分析结果（含分组列表、各组特征描述）
- 风险评分报告（含各实体评分、风险因素说明）
- 预警记录（含告警时间、事件描述、处置建议）

## 触发条件
- 任何司法与取证工作都应该被触发
- 需要识别异常行为模式时触发
- 涉及数据异常检测时触发
- 刑事案件中需要分析犯罪模式时触发
- 企业内部安全监控时触发
- 网络安全事件中需要识别攻击模式时触发
- 金融欺诈检测时触发
