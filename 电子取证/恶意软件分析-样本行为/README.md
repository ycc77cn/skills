# 恶意软件分析 样本行为

对恶意样本做静态特征、动态行为、家族归类、溯源与威胁情报关联分析。

## 用途

恶意软件是攻击的手。这个技能解决「它是什么、干了什么、归哪一类、谁做的」。

三条准则：

1. 静态先行。不跑样本先看结构，能拿到大半信息，风险也最低。
2. 动态隔离。必须运行时放进沙箱，全程记录文件、注册表、网络三类行为。
3. 结论落到 IoC。所有判断最终产出可检索的指标清单，供全网排查。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 样本基本信息 | 文件类型、壳与编译器、签名的识别 |
| 静态分析 | 字符串、导入表、资源、可疑代码段 |
| 动态行为分析 | 文件操作、注册表修改、进程、网络请求 |
| 分类分析 | 家族归类、功能判定、危害评估 |
| 溯源分析 | 攻击者画像、传播路径、关联样本 |
| 威胁情报关联 | IoC 比对、C2 识别、情报源交叉验证 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：勒索软件样本分析与解密支持、入侵事件恶意功能评估、钓鱼邮件恶意附件分析、终端安全事件排查、恶意工具技术分析。

## 能力边界

1. 仅用于合法授权范围内的样本分析；
2. 不提供样本制作、免杀或传播方法；
3. 样本在隔离环境处理，分析机不接入生产网络。
