# 技能名称：恶意软件分析

## 技能概述
对病毒、木马、勒索软件、间谍软件、Rootkit 等恶意软件进行深入分析，了解其功能、行为、传播方式和危害程度，为案件侦办和安全防护提供技术支撑。

---

## 核心能力

### 1. 样本基本信息分析
- **文件属性分析**：
  - 文件类型、大小、编译时间
  - PE 文件结构分析（导入表、导出表、节区信息）
  - ELF 文件结构分析
  - 数字签名验证（是否伪造签名）
- **哈希计算**：计算 MD5、SHA-1、SHA-256 哈希值，用于威胁情报查询。
- **字符串提取**：提取样本中的可读字符串（URL、IP、域名、路径、错误信息等）。
- **加壳/混淆识别**：识别常见的加壳工具（UPX、Themida、VMProtect 等）和混淆技术。

### 2. 静态分析
- **反编译/反汇编**：
  - 将二进制代码反汇编为汇编指令
  - 使用反编译工具生成伪代码（C 语言风格）
  - 分析程序的控制流和数据流
- **函数识别**：识别样本调用的关键 API 函数（如网络通信、文件操作、注册表操作）。
- **嵌入资源提取**：
  - 提取嵌入的配置文件、加密密钥、其他恶意文件
  - 提取图标、图片、版本信息等资源
- **导入/导出分析**：分析样本依赖的外部函数和自身导出的函数。

### 3. 动态行为分析
- **沙箱运行**：在隔离的虚拟环境中运行恶意样本，监控其行为。
- **文件系统监控**：记录样本创建、修改、删除的文件。
- **注册表监控**：记录样本对注册表的修改（启动项、服务注册等）。
- **网络行为监控**：
  - 记录样本发起的网络连接（DNS 查询、HTTP 请求、TCP 连接）
  - 捕获网络通信内容
  - 识别 C2 服务器地址
- **进程行为监控**：
  - 记录样本创建的子进程
  - 记录进程注入行为
  - 记录权限提升行为
- **API 调用追踪**：记录样本调用的所有 API 函数及其参数。

### 4. 恶意软件分类分析
- **勒索软件分析**：
  - 识别加密算法（AES、RSA、ChaCha20 等）
  - 分析加密行为（哪些文件被加密、加密速度）
  - 提取加密密钥（如果可能）
  - 识别勒索信息和解密工具
  - 检查是否存在免费解密工具（如 NoMoreRansom 项目）
- **木马/后门分析**：
  - 分析远程控制功能（屏幕监控、键盘记录、文件管理）
  - 提取 C2 通信协议和配置
  - 分析持久化机制（自启动方式）
- **挖矿软件分析**：
  - 识别挖矿算法和币种
  - 分析矿池地址和配置
  - 计算资源占用情况
- **信息窃取器分析**：
  - 分析窃取的数据类型（浏览器密码、Cookie、加密钱包、系统信息）
  - 分析数据回传方式和目标
- **Rootkit 分析**：
  - 分析隐藏机制（进程隐藏、文件隐藏、网络连接隐藏）
  - 分析内核级 hook 和 inline hook
  - 分析反检测和反调试技术

### 5. 溯源分析
- **编译环境分析**：从样本中提取编译器版本、开发环境信息。
- **代码相似度比对**：与已知恶意软件家族进行代码相似度比对。
- **C2 基础设施分析**：分析 C2 服务器的注册信息、IP 归属、历史行为。
- **传播路径分析**：分析样本的传播方式（钓鱼邮件、漏洞利用、供应链攻击）。
- **攻击者画像**：根据技术特征推断攻击者的技术水平、目标偏好。

### 6. 威胁情报关联
- **IoC 提取**：提取恶意 IP、域名、URL、文件哈希等威胁指标。
- **家族归属**：将样本归类到已知的恶意软件家族。
- **历史关联**：关联该样本与历史攻击事件的关联。
- **情报共享**：将分析结果输出为 STIX/MISP 等标准格式，用于情报共享。

---

## 适用场景
- 勒索软件攻击事件的样本分析和解密支持
- 网络入侵事件中恶意软件的功能和危害评估
- 钓鱼邮件中恶意附件/链接的分析
- 企业终端安全事件中的恶意软件排查
- 网络犯罪案件中的恶意工具技术分析

## 输出成果
- 恶意软件分析报告（含样本信息、行为描述、危害评估）
- IoC 清单（恶意 IP、域名、文件哈希等）
- C2 服务器信息（地址、协议、功能）
- 溯源分析报告（含攻击者画像、传播路径）
- 解密工具或方法（针对勒索软件）
- 威胁情报报告（STIX/MISP 格式）

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及恶意软件样本分析时触发
- 需要进行病毒检测与分析时触发
- 刑事案件中需要分析恶意程序时触发
- 企业网络安全事件中发现恶意软件时触发
- 恶意代码逆向工程时触发
- 系统感染恶意软件后的分析时触发
