# 数据库取证 库表记录

针对数据库做数据恢复、操作审计、篡改检测与安全分析，覆盖主流关系型与非关系型数据库。

## 用途

数据库里记的是账、是流水、是业务真相。这个技能解决「数据还在不在、谁动过、改了什么、有什么风险」。

三条准则：

1. 先取证再恢复。恢复动作要在镜像或副本上做，不动原始库。
2. 日志优先于结果。操作日志、事务日志、审计日志能还原动作顺序，比看最终数据更可靠。
3. 篡改看差异。用校验列、行版本、时间戳对不上号的地方定位篡改点。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 数据恢复 | 误删记录、被加密库、损坏库的恢复与导出 |
| 操作审计 | 登录、查询、修改、删除操作的完整时间线 |
| 篡改检测 | 记录差异比对、校验列验证、时间戳异常定位 |
| 安全分析 | 权限配置、账号状态、暴露面与加固建议 |
| 数据库类型 | 关系型与常见非关系型数据库的处理差异 |
| 数据提取导出 | 表结构与记录导出为 CSV、Excel、JSON |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：企业数据库被入侵后的篡改检测、内部人员违规修改记录调查、勒索软件加密库恢复、等级保护测评、交易数据篡改取证。

## 能力边界

1. 仅用于合法授权范围内的取证；
2. 不提供未授权访问他人数据库的手段；
3. 恢复结果受备份与日志留存情况限制，无法恢复时明确说明。
