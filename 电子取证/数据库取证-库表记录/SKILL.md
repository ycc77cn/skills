# 技能名称：数据库取证

## 技能概述
对各类数据库进行取证分析，包括数据恢复、操作审计、篡改检测、日志分析等。数据库是企业核心数据的存储载体，也是电子取证中经常需要重点分析的对象。

---

## 核心能力

### 1. 数据库数据恢复
- **表级恢复**：
  - 恢复被 DROP 的表及其数据
  - 恢复被 TRUNCATE 的表数据
  - 恢复被 DELETE 的记录
- **记录级恢复**：
  - 从数据页中直接提取被删除的记录
  - 利用事务日志（WAL/binlog/redo log）回放已提交但被删除的数据
  - 恢复 UPDATE 操作前的原始数据
- **BLOB/CLOB 恢复**：恢复存储在数据库中的大对象（文档、图片、音视频等）。
- **无密码恢复**：在不知道数据库密码的情况下，通过文件层面提取数据。
- **损坏修复**：修复损坏的数据库文件，恢复可读数据。

### 2. 数据库操作审计
- **操作日志分析**：
  - 分析事务日志（WAL），还原所有数据变更操作
  - 分析 binlog，还原所有 DML/DDL 操作
  - 分析审计日志，获取完整的操作记录
- **登录审计**：
  - 分析数据库登录记录（成功/失败）
  - 识别异常登录（异地登录、非工作时间登录、暴力破解）
  - 分析用户权限变更记录
- **查询审计**：
  - 分析慢查询日志，识别异常查询
  - 分析通用查询日志，获取所有 SQL 执行记录
  - 识别数据导出行为（SELECT INTO OUTFILE、mysqldump 等）

### 3. 数据篡改检测
- **数据完整性校验**：
  - 对比数据库备份与当前数据，识别被篡改的记录
  - 利用触发器日志或应用层日志验证数据一致性
- **时间线分析**：
  - 按时间顺序还原数据变更历史
  - 定位数据被篡改的确切时间点
  - 识别篡改操作对应的数据库用户和来源 IP
- **篡改模式识别**：
  - 批量修改（UPDATE 大量记录）
  - 精准修改（修改特定关键字段）
  - 插入伪造数据（INSERT 虚假记录）
  - 删除证据数据（DELETE/TRUNCATE 特定记录）

### 4. 数据库安全分析
- **权限配置审计**：
  - 检查用户权限是否过大（如普通用户拥有 DBA 权限）
  - 检查是否存在匿名访问
  - 审计存储过程和函数的安全性
- **漏洞检测**：
  - 检查数据库版本是否存在已知漏洞
  - 检查是否存在 SQL 注入风险
  - 检查加密配置（传输加密、存储加密）
- **后门检测**：
  - 检查是否存在隐藏账户
  - 检查是否存在恶意存储过程/触发器
  - 检查是否存在定时任务中的恶意操作

### 5. 支持的数据库类型
- **关系型数据库**：MySQL、PostgreSQL、Oracle、SQL Server、SQLite、MariaDB
- **NoSQL 数据库**：MongoDB、Redis、Elasticsearch、Cassandra
- **国产数据库**：达梦（DM）、人大金仓（KingbaseES）、OceanBase、TiDB
- **嵌入式数据库**：SQLite（手机 APP、浏览器等常用）

### 6. 数据提取与导出
- **结构化导出**：将数据库表导出为 CSV、Excel、JSON 等格式。
- **关联分析**：分析表之间的外键关系，构建数据关联图。
- **敏感数据识别**：自动识别数据库中的敏感字段（身份证号、手机号、银行卡号、密码等）。
- **数据脱敏**：对导出的敏感数据进行脱敏处理，保护个人隐私。

## 适用场景
- 企业数据库被入侵后的数据篡改检测
- 内部人员违规修改数据库记录的调查
- 数据库被勒索软件加密后的数据恢复
- 信息系统等级保护测评中的数据库安全检查
- 金融系统中交易数据被篡改的取证分析

## 输出成果
- 数据恢复报告（含恢复的表、记录数、数据样本）
- 操作审计报告（含操作时间线、异常操作清单）
- 篡改检测报告（含篡改记录、篡改时间、篡改来源）
- 安全分析报告（含漏洞清单、权限问题、加固建议）
- 数据导出文件（CSV/Excel/JSON 格式）

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及数据库数据取证时触发
- 需要分析数据库日志和记录时触发
- 刑事案件中需要提取数据库证据时触发
- 企业数据库安全调查时触发
- 数据库泄露事件分析时触发
- 数据库异常操作检测时触发
