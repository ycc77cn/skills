# 数据恢复 碎片重组

对被删除、损坏或加密破坏的数据做恢复，含文件签名识别、碎片拼接、数据库恢复与 RAID 重建。

## 用途

证据被删了不等于没了。这个技能解决「文件还能不能捞回来、碎片怎么拼、阵列崩了怎么重建」。

三条准则：

1. 原始介质只读。所有恢复操作在镜像上做，绝不在原始盘上写。
2. 先签名后内容。按文件签名扫描比按目录项找命中率更高。
3. 拼接要留依据。碎片重组的每步判断都记录依据与置信度，不硬拼。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 文件签名识别 | 按类型签名扫描未分配空间，恢复已删文件 |
| 碎片重组 | 碎片判定、拼接依据、置信度评估 |
| 数据库深度恢复 | 库文件损坏、记录级恢复与结构重建 |
| RAID 阵列恢复 | 阵列参数推断、条带重组、数据重建 |
| 特殊场景恢复 | 覆盖写入、固态盘 TRIM、加密破坏后的处理 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：嫌疑人销毁证据后的恢复、硬盘物理或逻辑损坏抢救、数据库被恶意删除后恢复、RAID 崩溃重建、企业数据丢失应急。

## 能力边界

1. 仅用于合法授权范围内的数据恢复；
2. 数据被覆盖或介质物理损坏严重时无法恢复，须明确告知；
3. 恢复结果附带哈希校验，完整性由委托方复核。
