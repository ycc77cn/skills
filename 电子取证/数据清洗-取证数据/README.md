# 数据清洗 取证数据

对多源取证数据做去重、标准化、异常值处理、缺失值填补、质量评估与脱敏。

## 用途

多设备、多平台导出的数据格式各异，直接分析必然出错。这个技能解决「先统一再分析」。

三条准则：

1. 清洗不改事实。只做格式统一与噪声剔除，不改原始值、不补造数据。
2. 每步可回溯。清洗规则、处理记录、保留与丢弃项全部留档。
3. 脱敏分级。对外输出的数据按需脱敏，内部留存保留原值。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 去重与合并 | 重复记录识别、多源合并、主记录选取 |
| 格式统一 | 时间、编码、字段名、单位、分隔符标准化 |
| 异常值处理 | 异常识别、标记与处置策略 |
| 缺失值处理 | 缺失模式分析、填补与保留策略 |
| 数据质量评估 | 完整性、一致性、准确性、唯一性评分 |
| 数据脱敏 | 手机号、身份证、银行卡等字段脱敏规则 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：多设备取证数据合并清洗、数据库导出标准化、日志去重与异常处理、跨平台数据统一格式化、分析前预处理。

## 能力边界

1. 不修改原始数据的事实内容，只做形式统一；
2. 不填补关键证据字段，缺失即标注缺失；
3. 脱敏规则需按委托要求确认后执行。
