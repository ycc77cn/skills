# 数据采集 证据固定

对硬盘、手机、服务器、云平台等多类数据源做安全、完整、合规的采集与固定，保证采集过程不改动原始数据、结果可验证。

## 用途

取证的第一步是拿到可信的数据副本。这个技能把采集动作标准化：先做只读镜像，再做哈希校验，再做防篡改监控，最后形成可追溯的采集记录。

三条准则：

1. 只读优先。能不写就不写，必须写时先镜像再操作。
2. 双哈希留证。采集前后各算一次哈希，前后一致才认定未被篡改。
3. 全程可追溯。采集人、时间、设备、方式、结果全部落记录。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 镜像采集与哈希校验 | 物理镜像、逻辑镜像、目录级采集，采集前后哈希比对 |
| 异常数据自动识别 | 隐藏分区、未分配空间、异常文件、可疑对象的自动提取 |
| 多设备并行采集 | 多目标同时采集时的顺序编排与结果归集 |
| 防篡改监控 | 写保护、访问审计、采集过程完整性监控 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：现场电子物证提取、企业合规审计的数据保全、民事纠纷的证据固定、安全事件应急响应。

## 能力边界

1. 仅用于合法授权范围内的数据采集；
2. 不提供绕过设备锁、破解加密的采集手段；
3. 采集动作本身不替代司法鉴定程序，结果需按法定流程确认。
