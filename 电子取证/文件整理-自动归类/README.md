# 文件整理 自动归类

在生成或整理文件时统一目录结构与命名，把散落文件归位，输出整理报告与变更清单。

## 用途

取证数据一多，文件就乱。这个技能解决「文件放哪、怎么命名、引用怎么跟着改」。

三条准则：

1. 先定结构再放文件。目录按功能分层，不按时间堆。
2. 命名可读。看到文件名就知道是什么，不用点开猜。
3. 移动必须同步改引用。文件挪了，导入路径与配置要一起改。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 文件命名规范 | 语义化命名、时间与版本标注、禁用字符 |
| 目录结构规范 | 分层标准、层级深度、职责边界 |
| 文件分类标准 | 代码、配置、文档、测试、资源五类归属 |
| 自动整理规则 | 各类文件的落位规则与例外处理 |
| 整理执行流程 | 生成时整理、批量整理两种触发方式 |
| 防错机制 | 移动前备份、引用扫描、回滚方案 |

## 内部结构

```text
文件整理-自动归类/
├── SKILL.md        # 主文件：命名与目录规范、分类规则、执行流程
└── README.md       # 本文件
```

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：AI 生成新代码文件时自动落位、项目结构混乱需整理、根目录文件散落、多人协作需统一结构。

## 能力边界

1. 只做结构与命名整理，不改文件内容；
2. 不处理需要业务判断的模块拆分决策；
3. 批量移动前必须备份，可回滚。
