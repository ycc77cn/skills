# 技能名称：文件自动整理

## 技能概述
自动整理AI生成的文件，确保文件按照规范的目录结构和命名约定进行组织和存储。避免文件散落、命名混乱的问题，提高项目文件的可维护性和可读性。

---

## 核心能力

### 1. 文件命名规范
- **统一命名风格**：
  - 使用小写字母和数字，单词间用下划线分隔（如 `user_auth.py`）
  - 避免使用中文文件名
  - 保持简洁明了，能够表达文件功能
- **文件前缀约定**：
  - 工具类文件：`util_*.py`
  - 配置类文件：`config_*.py` 或 `*.config.js`
  - 测试类文件：`test_*.py` 或 `*_test.py`
  - 组件类文件：`component_*.vue` 或 `*_component.ts`
- **版本号管理**：如有需要，使用 `v1_v2_v3` 格式

### 2. 目录结构规范
```
项目根目录/
├── src/                    # 源代码目录
│   ├── components/         # 组件目录
│   ├── utils/              # 工具函数目录
│   ├── services/           # 服务层目录
│   ├── models/             # 数据模型目录
│   └── views/              # 视图目录
├── docs/                   # 文档目录
├── tests/                  # 测试目录
├── config/                 # 配置文件目录
├── scripts/                # 脚本目录
├── temp/                   # 临时文件目录
├── data/                   # 数据文件目录
├── assets/                # 静态资源目录
└── README.md               # 项目说明文件
```

### 3. 文件分类标准
- **代码文件**：`.py`, `.js`, `.ts`, `.vue`, `.go`, `.java`, `.cpp`, `.c`, `.h`
- **配置文件**：`.json`, `.yaml`, `.yml`, `.toml`, `.ini`, `.conf`, `.env`
- **文档文件**：`.md`, `.txt`, `.pdf`, `.doc`, `.docx`
- **数据文件**：`.csv`, `.xlsx`, `.xls`, `.db`, `.sql`
- **图片资源**：`.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.ico`
- **样式文件**：`.css`, `.scss`, `.sass`, `.less`
- **构建文件**：`Makefile`, `Dockerfile`, `Jenkinsfile`

### 4. 自动整理规则

#### 4.1 代码文件整理
- 根据文件扩展名移动到对应语言目录
- Python文件 → `src/` 或 `src/python/`
- JavaScript/TypeScript文件 → `src/` 或 `src/js/`
- Vue组件 → `src/components/`
- Go文件 → `src/` 或 `src/go/`

#### 4.2 配置文件整理
- 全局配置文件 → `config/`
- 环境配置文件 → `config/env/`
- 敏感配置（.env）→ 仅在 `config/` 中保留模板

#### 4.3 文档文件整理
- 项目文档 → `docs/`
- API文档 → `docs/api/`
- 笔记和临时文档 → `docs/notes/` 或 `temp/`

#### 4.4 测试文件整理
- 单元测试 → `tests/unit/`
- 集成测试 → `tests/integration/`
- 端到端测试 → `tests/e2e/`

#### 4.5 资源文件整理
- 图片资源 → `assets/images/`
- 图标资源 → `assets/icons/`
- 字体资源 → `assets/fonts/`

### 5. 整理执行流程

#### 5.1 文件生成时
1. 分析文件类型和用途
2. 根据命名规范检查文件名是否合规
3. 确定文件应存放的目标目录
4. 创建必要的目录结构
5. 将文件移动到正确位置
6. 更新相关的导入路径

#### 5.2 批量整理时
1. 扫描项目目录，识别所有文件
2. 分析文件类型和内容
3. 根据分类标准生成分类报告
4. 执行文件移动/重命名操作
5. 生成整理报告和变更记录

### 6. 防错机制
- **备份机制**：整理前自动备份原文件
- **冲突检测**：检测目标位置是否已存在同名文件
- **依赖检查**：检查文件引用关系，避免破坏导入路径
- **回滚机制**：提供整理操作的回滚能力

---

## 适用场景
- AI 生成新代码文件时
- 项目文件结构混乱时
- 需要规范化项目结构时
- 文件散落在根目录时
- 多人协作项目需要统一结构时

## 输出成果
- **整理报告**：包含整理前后对比、文件移动记录
- **目录结构图**：整理后的项目目录树
- **变更清单**：列出所有文件的重命名和移动操作
- **导入路径更新清单**：需要更新的文件引用列表

## 触发条件
- 任何涉及文件操作的任务都应该被触发
- 涉及文件生成时自动触发
- 涉及文件整理时自动触发
- 项目结构混乱需要整理时触发
- 任何文件创建、修改、移动操作时触发
- 任何涉及目录结构的任务时触发
