# 文本分析 NLP挖掘

对聊天记录、邮件、文档、网页等文本做语义检索、关系图谱、时序分析与多语言处理。

## 用途

文本证据量最大、噪声最多。这个技能解决「怎么从几万条聊天里找关键的那几十条、人和人是什么关系、暗语指什么」。

三条准则：

1. 语义检索优先。按意图找，不靠关键词硬匹配，避免换个说法就漏。
2. 关系靠证据连。人物关系图谱的每条边都要落到具体原文，不凭空推断。
3. 暗语要落地。案件专属黑话必须给出释义与出现位置，不猜。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 语义意图检索 | 按意图召回原文、上下文还原、置信度标注 |
| 关系图谱构建 | 人物、账号、群组的关系网络与关键节点 |
| 时序与行为分析 | 沟通时间线、活跃规律、异常行为清单 |
| 跨语言与多模态 | 多语言文本处理、图文混排内容解析 |
| 情感与态度分析 | 情绪倾向、威胁与胁迫语句识别 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：电信诈骗聊天记录分析、洗钱资金沟通审查、犯罪团伙架构梳理、网络暴力与威胁取证、跨境多语言通信分析。

## 能力边界

1. 仅用于合法授权范围内的文本分析；
2. 语义检索结果为候选集，需人工复核后采用；
3. 关系推断必须附原文出处，无出处不作结论。
