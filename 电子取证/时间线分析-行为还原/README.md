# 时间线分析 行为还原

把多源时间数据整合成统一时间线，还原事件顺序、行为模式与关键节点。

## 用途

案件讲不清顺序就讲不清事实。这个技能解决「谁先谁后、时间戳可不可信、多台设备怎么对齐」。

三条准则：

1. 时区先统一。所有时间换算到同一基准后再排序，避免错位。
2. 时间戳分可信度。系统时间可被篡改，文件创建时间可被伪造，要分级采信。
3. 事件要有出处。时间线上每个点都标明数据来源，不合并无来源的推断。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 多源时间整合 | 文件系统、日志、应用、网络、设备时间的归集 |
| 时间线构建 | 时间轴生成、关键节点标注、可视化呈现 |
| 行为模式分析 | 活跃规律、异常行为、行为段落划分 |
| 关键事件定位 | 事件时间窗、证据来源、事件描述 |
| 多设备关联 | 跨设备时间对齐与事件归并 |
| 时间戳验证 | 篡改识别、真实时间还原、可信度分级 |

## 内部结构

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：入侵事件攻击时间线还原、内部人员违规行为分析、交通事故手机使用时间确认、数据泄露时间窗确定、多设备多数据源关联分析。

## 能力边界

1. 仅用于合法授权范围内的分析；
2. 系统时间被篡改时，还原结果需标注推断依据与不确定区间；
3. 时间线不替代事实认定，只提供顺序参考。
