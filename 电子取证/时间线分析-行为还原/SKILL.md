# 技能名称：时间线与行为分析

## 技能概述
将多个数据源中的时间戳信息整合，构建统一的时间线，还原事件发生的完整过程，分析用户行为模式，定位异常行为和关键事件节点。时间线分析是电子取证中串联零散证据、还原案件事实的核心方法。

---

## 核心能力

### 1. 多源时间数据整合
- **系统事件时间线**：
  - Windows 事件日志（登录、注销、文件访问、服务启停、错误事件）
  - Linux 系统日志（auth.log、syslog、lastlog）
  - macOS 系统日志（Unified Logs）
- **文件系统时间线**：
  - 文件创建、修改、访问时间（MACE 时间戳）
  - 文件删除时间
  - 文件下载时间
  - USB 设备连接/断开时间
- **网络活动时间线**：
  - 网络连接建立/断开时间
  - DNS 查询时间
  - Web 访问时间
  - 邮件发送/接收时间
- **应用活动时间线**：
  - 即时通讯消息时间
  - 文档编辑时间
  - 浏览器访问时间
  - APP 使用时间
- **设备活动时间线**：
  - 手机通话时间
  - GPS 定位时间
  - 蓝牙/WiFi 连接时间
  - 设备开关机时间

### 2. 时间线构建与可视化
- **统一时间轴**：将所有数据源的时间信息整合到一条统一的时间轴上。
- **多层级展示**：
  - 概览层级：展示关键事件和时间段
  - 详细层级：展示每个事件的详细信息
  - 过滤层级：按事件类型、来源、关键词筛选
- **时间轴标注**：在时间轴上标注关键事件（如"首次登录""文件删除""异常连接"）。
- **时间间隔分析**：计算事件之间的时间间隔，识别异常的时间间隙或密集活动。

### 3. 用户行为模式分析
- **日常行为基线**：建立用户的正常行为模式（活跃时段、常用应用、常用网站）。
- **行为异常检测**：
  - 非工作时间活动（如凌晨 3 点的文件操作）
  - 异常的应用使用（如突然使用加密工具、数据擦除工具）
  - 异常的文件操作（如批量删除、大批量复制到 USB）
  - 异常的网络行为（如突然访问陌生网站、大量数据上传）
- **行为序列分析**：分析用户操作的先后顺序，还原完整的操作流程。
- **行为频率分析**：统计各类操作的频率，识别异常高频或低频行为。

### 4. 关键事件定位
- **入侵时间点确定**：通过日志分析确定攻击者首次入侵的时间。
- **数据泄露时间窗口**：确定数据被窃取的时间范围。
- **证据销毁时间**：确定嫌疑人删除或擦除证据的时间。
- **异常登录时间**：定位异常的登录事件（异地登录、非工作时间登录）。
- **设备接入时间**：确定 USB 设备、外部硬盘等外设接入和断开的时间。

### 5. 多设备时间关联
- **跨设备时间对齐**：将不同设备（电脑、手机、平板）的时间线进行对齐。
- **时区处理**：自动处理不同时区的时间戳，统一转换为标准时间。
- **事件关联**：识别不同设备上同时发生的相关事件。
- **因果分析**：分析事件之间的因果关系（如手机收到验证码→电脑登录成功）。

### 6. 时间戳完整性验证
- **时间一致性检查**：验证不同数据源的时间戳是否一致。
- **时钟偏差分析**：检测系统时钟是否被修改或存在偏差。
- **时间反篡改**：通过多源交叉验证，还原被篡改的时间戳。
- **时间精度分析**：评估不同数据源时间戳的精度和可靠性。

---

## 适用场景
- 入侵事件中攻击时间线的还原
- 内部人员违规操作的行为分析
- 交通事故中当事人手机使用时间的确认
- 数据泄露事件中泄露时间窗口的确定
- 复杂案件中多设备、多数据源的时间关联分析

## 输出成果
- 统一时间线报告（含所有事件的时间轴）
- 行为分析报告（含行为模式、异常行为清单）
- 关键事件定位报告（含事件时间、描述、证据来源）
- 多设备关联时间线
- 时间戳完整性验证报告
- 可视化时间轴图表

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及事件时间线构建时触发
- 需要分析行为模式时触发
- 刑事案件中需要还原事件发生顺序时触发
- 企业安全事件时序分析时触发
- 事故原因分析时触发
- 用户行为异常检测时触发
