# 沙箱执行 隔离运行

在受控隔离环境中安全执行可疑文件与取证脚本，监控行为、记录过程、验证操作。

## 用途

没跑过就不知道样本真会干什么，但直接跑会中招。这个技能解决「怎么跑得安全、跑完留下什么」。

三条准则：

1. 默认断网。需要联网观察时单独开受限通道，不直连生产网络。
2. 快照起步。每次执行从干净快照开始，跑完回滚，保证可复现。
3. 行为全记录。文件、注册表、进程、网络、API 调用五类行为同步采集。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：可疑文件与恶意样本安全分析、取证脚本执行前预验证、恶意行为动态监控、批量样本自动化分析、取证操作隔离执行。

## 能力边界

1. 仅用于合法授权范围内的样本与脚本执行；
2. 不提供沙箱逃逸或检测规避手段；
3. 部分样本识别虚拟环境后不触发行为，需说明环境局限性。
