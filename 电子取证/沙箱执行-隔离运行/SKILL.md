# 技能名称：沙箱环境执行

## 技能概述
在隔离的安全沙箱环境中执行取证操作和验证任务，确保分析过程不会对原始证据造成影响，同时防止恶意代码扩散。沙箱环境提供可控的执行空间，支持对可疑文件、恶意样本、未知程序进行安全分析。

---

## 核心能力

### 1. 沙箱环境管理
- **环境创建**：
  - 快速创建隔离的沙箱执行环境（虚拟机、容器）
  - 支持多种操作系统模板（Windows 7/10/11、Ubuntu、CentOS、macOS）
  - 自定义环境配置（CPU、内存、磁盘、网络）
  - 预装取证工具和分析软件
- **环境快照**：
  - 在执行前创建干净的环境快照
  - 执行完成后可回滚到干净状态
  - 支持多版本快照管理
- **环境销毁**：
  - 任务完成后安全销毁沙箱环境
  - 确保所有数据被彻底清除
  - 防止数据残留泄露

### 2. 可疑文件安全执行
- **恶意样本分析**：
  - 在沙箱中安全执行可疑文件（.exe、.bat、.ps1、.py 等）
  - 监控样本的所有行为（文件操作、注册表修改、网络连接、进程创建）
  - 记录完整的执行轨迹
- **文档文件分析**：
  - 在沙箱中打开可疑文档（Office 文档、PDF 等）
  - 监控宏代码执行、漏洞利用行为
  - 捕获文档触发的所有操作
- **脚本文件执行**：
  - 在沙箱中执行 PowerShell、Python、Bash 等脚本
  - 监控脚本的系统调用和外部请求
  - 记录脚本的输入和输出
- **安装包分析**：
  - 在沙箱中安装可疑的安装程序
  - 监控安装过程中的文件释放、服务注册、驱动安装
  - 分析安装包的完整行为

### 3. 行为监控与记录
- **文件系统监控**：
  - 记录所有文件的创建、修改、删除操作
  - 记录文件的重命名和属性变更
  - 捕获被释放的文件内容
- **注册表监控**：
  - 记录所有注册表的修改操作
  - 监控启动项、服务、驱动等关键位置的变更
- **网络行为监控**：
  - 拦截和记录所有网络请求（DNS、HTTP、TCP、UDP）
  - 模拟网络响应（DNS 解析、HTTP 回应）
  - 记录 C2 通信的完整内容
- **进程行为监控**：
  - 记录进程的创建和终止
  - 监控进程注入、DLL 加载
  - 记录进程间的通信
- **API 调用监控**：
  - 拦截和记录关键的 Windows API 调用
  - 分析 API 调用序列和参数

### 4. 取证操作验证
- **工具执行验证**：
  - 在沙箱中先运行取证工具，验证命令和参数的正确性
  - 确认工具输出符合预期后再在正式环境中执行
  - 避免因命令错误导致原始证据损坏
- **脚本预执行**：
  - 在沙箱中测试自动化取证脚本
  - 验证脚本的逻辑和输出
  - 确认脚本不会产生副作用
- **数据恢复验证**：
  - 在沙箱中验证数据恢复操作的效果
  - 确认恢复的数据完整可用
  - 评估不同恢复方法的成功率

### 5. 多沙箱并行执行
- **并行分析**：
  - 同时创建多个沙箱环境，并行分析不同样本
  - 提高批量分析的效率
- **对比分析**：
  - 在不同配置的沙箱中执行同一样本，对比行为差异
  - 分析样本的环境检测和适应行为
- **关联分析**：
  - 关联多个样本在沙箱中的行为，发现共同特征

### 6. 安全隔离保障
- **网络隔离**：
  - 沙箱默认完全断网
  - 可配置虚拟网络接口，模拟特定网络环境
  - 所有网络流量被拦截和记录
- **资源限制**：
  - 限制沙箱的 CPU、内存、磁盘使用量
  - 防止恶意代码消耗过多资源
  - 设置执行超时时间
- **逃逸防护**：
  - 检测虚拟机逃逸尝试
  - 检测沙箱检测和反分析技术
  - 限制沙箱内的权限提升操作

## 适用场景
- 可疑文件和恶意样本的安全分析
- 取证工具和脚本执行前的预验证
- 恶意软件行为的动态监控
- 批量样本的自动化分析
- 取证操作的安全隔离执行

## 输出成果
- 沙箱执行报告（含环境配置、执行时间、资源使用）
- 行为监控日志（含文件操作、注册表修改、网络请求）
- 进程树和 API 调用记录
- 网络流量捕获文件（PCAP）
- 释放文件清单（含文件哈希）
- 截图和录屏记录

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及沙箱环境执行时触发
- 需要安全执行可疑程序时触发
- 刑事案件中需要分析恶意软件时触发
- 企业安全测试时触发
- 可疑文件行为分析时触发
- 零日漏洞检测时触发
