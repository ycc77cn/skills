# 环境仿真 运行还原

把磁盘镜像、数据库、手机、网络环境还原成可交互的运行环境，用于查看、验证与演示。

## 用途

静态取证看不到系统「怎么跑」。这个技能解决「把当时的环境复原出来，实际操作一遍」。

三条准则：

1. 原镜像不动。仿真一律在副本或快照上做，原始证据只读保存。
2. 操作全录。屏幕录像加操作日志，演示过程可回溯。
3. 结果要比对。仿真环境与原始环境做一致性验证，避免「仿出来的不是原来的」。

## 覆盖范围

| 板块 | 内容 |

| 磁盘镜像仿真 | 电脑环境还原、桌面与文件交互查看 |
| 数据库仿真 | 库还原、查询验证、数据比对 |
| 手机环境仿真 | 设备环境还原、应用界面与数据查看 |
| 网络环境仿真 | 网络拓扑还原、攻击过程重现 |
| 仿真环境管理 | 快照、回滚、隔离、资源与一致性校验 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：交互式查看嫌疑人电脑桌面与文件、验证涉案软件功能行为、数据库还原与查询验证、重现网络攻击过程、法庭演示涉案系统运行状态。

## 能力边界

1. 仅用于合法授权范围内的仿真；
2. 不提供规避授权或隐藏操作痕迹的仿真方式；
3. 硬件依赖强的环境无法完整还原时，明确标注差异。
