# 电子邮件取证 客户端邮箱

对邮件做头部溯源、内容分析、附件检测与账户取证，还原邮件的真实来源与通信关系。

## 用途

邮件是最容易伪造的通信方式，发件人名字可以随便写，头部记录骗不了人。这个技能解决「谁真正发的、从哪发的、内容有没有问题、附件安不安全」。

三条准则：

1. 头部是根本。Received 链、SPF/DKIM/DMARC 结果、Message-ID 决定真伪，正文说明不了来源。
2. 附件单独隔离。附件一律在隔离环境分析，不在取证主机直接打开。
3. 时间要换算。邮件头时间常带时区偏差，统一换算后再入时间线。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 邮件头分析 | 投递路径、发件 IP、伪造识别、认证结果判读 |
| 邮件内容分析 | 正文结构、恶意链接、追踪像素、隐藏内容 |
| 附件分析 | 附件类型识别、恶意附件检测、宏与脚本检查 |
| 邮件账户取证 | 客户端本地库、服务器邮箱、账户配置与登录记录 |
| 邮件元数据 | 收发时间、参与者、主题聚类、通信频次 |
| 邮件服务器取证 | 服务端日志、队列记录、投递失败与转发规则 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：钓鱼邮件事件调查、商业秘密泄露邮件提取、网络诈骗通信记录分析、勒索邮件来源追踪、企业内部邮件合规审计。

## 能力边界

1. 仅用于合法授权范围内的邮件取证；
2. 不提供伪造邮件或绕过邮件认证的方法；
3. 加密邮件与匿名转发链无法完全还原时，明确标注。
