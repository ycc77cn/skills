# 技能名称：电子邮件取证

## 技能概述
对电子邮件系统进行全面取证分析，包括邮件头解析、内容提取、附件分析、投递路径追踪等。电子邮件是网络犯罪（钓鱼、诈骗、勒索、商业间谍）中最常用的工具之一，邮件取证是电子取证的重要领域。

---

## 核心能力

### 1. 邮件头深度分析
- **发件人追踪**：
  - 解析 From、Reply-To、Sender 等字段的差异，识别伪造发件人
  - 分析 Received 字段链，追踪邮件的真实投递路径
  - 识别邮件是否通过匿名转发服务发送
- **IP 地址提取**：从 Received 字段中提取发件人的真实 IP 地址。
- **邮件服务器信息**：识别发件人使用的邮件服务器和客户端软件。
- **时间线分析**：从 Date 字段和各 Received 字段中还原邮件的完整传递时间线。
- **SPF/DKIM/DMARC 验证**：验证邮件的域名验证记录，判断邮件是否被伪造。

### 2. 邮件内容分析
- **正文提取**：提取纯文本和 HTML 格式的邮件正文。
- **嵌入资源提取**：提取邮件中嵌入的图片、样式表、脚本等资源。
- **追踪像素检测**：识别邮件中的追踪像素（web beacon），分析其指向的服务器。
- **恶意链接检测**：
  - 识别邮件中的恶意链接（钓鱼网站、恶意软件下载链接）
  - 分析链接的跳转链路（短链接还原）
  - 提取链接中的参数信息（如收件人标识、活动标识）
- **钓鱼特征识别**：
  - 识别钓鱼邮件的常见特征（紧迫性、伪造品牌、异常链接）
  - 分析钓鱼邮件的模板和话术
  - 关联已知的钓鱼攻击活动

### 3. 附件分析
- **附件提取**：提取邮件中的所有附件文件。
- **文件类型识别**：识别附件的真实文件类型（防止扩展名伪造）。
- **恶意附件检测**：
  - 检测恶意文档（含宏病毒的 Office 文档）
  - 检测可执行文件（.exe、.scr、.bat 等）
  - 检测压缩包中的恶意文件
  - 检测 PDF 中的恶意脚本和漏洞利用
- **Office 宏分析**：提取和分析 Office 文档中的 VBA 宏代码。
- **DDE 攻击检测**：识别利用 DDE（动态数据交换）的攻击。

### 4. 邮件账户取证
- **邮箱数据提取**：
  - 提取邮箱中的所有邮件（收件箱、发件箱、草稿箱、已删除）
  - 提取通讯录、日历、任务、便签
  - 提取邮件规则和过滤器配置
- **邮件客户端分析**：
  - Outlook（PST/OST 文件分析）
  - Thunderbird（MBOX 文件分析）
  - Foxmail
  - Apple Mail
- **Web 邮箱分析**：
  - 通过 API 或页面导出获取 Web 邮箱数据
  - 分析邮箱登录记录

### 5. 邮件元数据分析
- **通信关系分析**：构建邮件通信关系网络（发件人-收件人关系图）。
- **通信频率分析**：统计邮件通信频率，识别异常通信模式。
- **群发邮件识别**：识别批量发送的邮件（垃圾邮件、钓鱼邮件）。
- **邮件大小分析**：识别异常大附件邮件（可能涉及数据外泄）。
- **时间模式分析**：分析邮件发送时间规律（如深夜发送的异常邮件）。

### 6. 邮件服务器取证
- **邮件日志分析**：
  - 分析邮件服务器的发送/接收日志
  - 追踪邮件的完整投递路径
  - 识别邮件投递失败的原因
- **邮件队列分析**：检查邮件队列中的待发送邮件。
- **邮件备份恢复**：从邮件服务器的备份中恢复已删除邮件。

---

## 适用场景
- 钓鱼邮件攻击事件调查
- 商业秘密泄露案件中邮件证据的提取
- 网络诈骗案件中邮件通信记录分析
- 勒索邮件的来源追踪
- 企业内部邮件合规审计

## 输出成果
- 邮件头分析报告（含投递路径、发件人 IP、伪造检测）
- 邮件内容分析报告（含恶意链接、追踪像素检测结果）
- 附件分析报告（含恶意附件检测结果）
- 通信关系图谱
- 邮件时间线
- 邮件服务器日志分析报告

## 触发条件
- 任何司法与取证工作都应该被触发
- 涉及电子邮件证据分析时触发
- 需要提取和分析邮件内容时触发
- 刑事案件中需要分析邮件证据时触发
- 企业内部调查需要分析邮件时触发
- 民事纠纷中需要邮件证据时触发
- 邮件诈骗案件分析时触发
