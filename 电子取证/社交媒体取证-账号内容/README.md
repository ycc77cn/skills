# 社交媒体取证 账号内容

针对国内与国际社交平台做内容固定、账号溯源、传播分析与非法内容识别。

## 用途

社交平台数据删得快、改得快。这个技能解决「怎么固定才有效、账号背后是谁、内容怎么传开的」。

三条准则：

1. 固定要带环境。截图、链接、页面结构、访问时间、设备信息一并留存，单张截图证明力不足。
2. 跨平台关联。同一人在不同平台的头像、昵称、手机号、活跃时段可做关联，单一平台不下身份结论。
3. 传播看节点。转发链路里的关键节点往往比内容本身更能说明组织性。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 国内平台取证 | 主流内容与社交平台的账号、作品、评论、私信固定 |
| 国际平台取证 | 海外平台的公开内容采集与留存 |
| 账号溯源与身份识别 | 跨平台关联、行为特征比对、虚拟身份归并 |
| 内容传播分析 | 传播链路、关键节点、扩散时间线 |
| 非法内容检测 | 违法与违规内容识别、批量筛查 |
| 数据保全与固定 | 哈希固化、时间戳记录、结构化归档 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：网络暴力与欺凌取证、谣言传播溯源、诈骗推广链追踪、名誉权侵权内容固定、违法信息发现取证。

## 能力边界

1. 仅采集公开信息或在合法授权范围内的数据；
2. 不提供绕过平台风控、批量爬取私域数据的方法；
3. 账号身份关联为概率判断，需链下证据佐证。
