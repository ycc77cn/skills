# 移动设备取证 安卓苹果

针对手机、平板等移动设备做数据提取与分析，覆盖 iOS 与 Android 两大体系，含应用级深度分析。

## 用途

移动设备是案件里信息密度最高的载体。这个技能解决「怎么取、取到什么、怎么用」三个问题。

三条准则：

1. 提取方式分级。逻辑提取、文件系统提取、物理提取按设备条件选，不强求最高档。
2. 应用优先。聊天、支付、位置、出行类应用的数据价值最高，先取这些。
3. 哈希与来源同步记录。每条数据标清来源应用、路径与提取方式。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 数据提取方式 | 逻辑提取、备份解析、文件系统提取、物理提取的适用条件 |
| iOS 设备 | 备份结构、钥匙串、应用沙盒、系统数据库 |
| Android 设备 | 分区结构、应用数据目录、系统数据库、权限与 root 状态 |
| 通用分析 | 通讯录、通话、短信、日历、备忘录、位置、WiFi 记录 |
| 应用深度分析 | 聊天记录、支付流水、出行轨迹、社交与内容类应用数据 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：电信诈骗案件手机数据提取、走私贩毒案件通信记录取证、交通事故手机使用证据提取、家庭纠纷通信记录保全。

## 能力边界

1. 仅用于合法授权范围内的设备取证；
2. 不提供破解设备锁、绕过加密的未授权手段；
3. 提取结果受设备型号与系统版本影响，无法覆盖的部分明确标注。
