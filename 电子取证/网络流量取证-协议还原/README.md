# 网络流量取证 协议还原

对网络流量做捕获、协议解析、会话重建与异常检测，从数据包里还原通信内容与行为。

## 用途

流量是「发生在网络上」的原始记录。这个技能解决「包里有什么、谁在和谁说话、内容能不能还原、有没有藏着东西」。

三条准则：

1. 捕获要有边界。明确抓取位置、时长与过滤条件，避免无效数据淹没关键包。
2. 先会话后内容。按会话重组再看内容，单包判断容易误读。
3. 隐蔽通道单独查。常规协议之外的隧道、隐写、非标准端口要单列检查。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：网络入侵事件流量回溯、内部数据泄露追踪、非法网络通信取证、DDoS 特征分析、恶意软件网络行为分析。

## 能力边界

1. 仅用于合法授权范围内的流量分析；
2. 加密流量无法直接还原内容，只能做元数据与行为分析；
3. 不提供入侵他人网络的抓包方法。
