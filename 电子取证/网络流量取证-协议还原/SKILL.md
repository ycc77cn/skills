# 技能名称：网络流量取证

## 技能概述
对网络通信数据进行捕获、还原和分析，从网络流量中提取文件、通信内容、攻击行为等关键证据。适用于网络入侵调查、数据泄露追踪、非法通信监控等场景。

---

## 核心能力

### 1. 流量捕获与保存
- **实时抓包**：在网络关键节点（网关、交换机镜像端口）实时捕获网络流量。
- **全量保存**：将捕获的流量以 PCAP/PCAPNG 格式完整保存，确保数据可复现。
- **定向采集**：按 IP、端口、协议、时间范围等条件定向采集特定流量。
- **加密流量捕获**：捕获 TLS/SSL 加密流量，配合证书或密钥进行解密分析。

### 2. 协议深度分析
- **HTTP/HTTPS 分析**：
  - 还原 HTTP 请求和响应内容
  - 提取上传/下载的文件
  - 分析 Web 应用攻击痕迹（SQL 注入、XSS 等）
  - Cookie 和 Session 分析
- **DNS 分析**：
  - 查询域名记录
  - 检测 DNS 隧道和 DGA（域名生成算法）域名
  - 恶意域名关联分析
- **邮件协议分析**：
  - 还原 SMTP/POP3/IMAP 通信
  - 提取邮件内容和附件
  - 分析钓鱼邮件的投递路径
- **文件传输分析**：
  - FTP/SFTP 传输内容还原
  - 提取传输的文件
  - 分析文件传输行为模式
- **即时通信分析**：
  - 分析微信、QQ、Telegram 等通信协议特征
  - 提取通信元数据（时间、大小、频率）

### 3. 隐蔽通道检测
- **DNS 隧道**：检测通过 DNS 查询/响应传输数据的行为。
- **ICMP 隧道**：检测通过 ICMP 包载荷传输数据的行为。
- **HTTP 隐写**：检测在 HTTP 头部、Cookie 中隐藏数据的行为。
- **加密流量异常**：识别伪装成正常流量的恶意通信（如使用非标准端口、异常证书）。
- **流量分片重组**：将分散在多个包中的数据重新组装，还原完整内容。

### 4. 会话重建与内容提取
- **TCP 会话重建**：将 TCP 流重组为完整的会话内容。
- **文件自动提取**：从网络流量中自动提取传输的文件（图片、文档、压缩包、可执行文件等）。
- **语音/视频提取**：从 SIP/RTP 流量中提取 VoIP 通话内容。
- **数据库通信还原**：还原数据库查询语句，分析数据访问行为。

### 5. 流量行为分析
- **流量基线分析**：建立正常流量基线，识别偏离基线的异常流量。
- **通信模式分析**：分析主机间的通信频率、数据量、时间规律。
- **C2 通信检测**：识别与命令控制服务器的周期性心跳通信。
- **数据外泄检测**：识别大量数据向外部传输的行为。
- **横向移动检测**：识别内网中异常的扫描和连接行为。

---

## 适用场景
- 网络入侵事件的流量回溯分析
- 内部数据泄露事件的追踪
- 非法网络通信的监控与取证
- DDoS 攻击的流量特征分析
- 恶意软件网络行为的分析

## 输出成果
- 流量分析报告（含协议分布、通信统计）
- 提取文件清单（含文件类型、大小、来源/目标）
- 会话还原记录（含通信内容、时间、双方信息）
- 异常流量告警清单
- 隐蔽通道检测报告
- PCAP 证据文件（含哈希校验）

- 需要进行网络数据包捕获与分析时触发
- 刑事案件中需要分析网络通信时触发
- 企业网络安全监控时触发
- 网络攻击检测与溯源时触发
- 网络异常流量识别时触发
