# 证据合规 司法报告

把取证全过程纳入法律合规要求，管理证据链完整性，自动生成司法鉴定报告并支持可视化展示与出庭。

## 用途

证据能不能用，取决于程序合不合规、链条断没断。这个技能解决「流程合规、链条完整、报告能出庭」。

三条准则：

1. 程序优先。取证方式、授权文书、见证记录缺项，报告不予出具。
2. 链条不断。每一环都做哈希校验与流转记录，断点必须说明原因。
3. 报告可质证。报告内容必须有对应的检验过程与证据附件支撑。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 取证过程合规 | 程序检查、授权管理、见证记录、全程录像、操作审计 |
| 证据链完整性 | 流转记录、哈希校验链、存储安全、访问控制、封存启封 |
| 司法报告生成 | 报告模板、内容自动填充、报告编号、多格式导出 |
| 可视化展示 | 关系图谱、时间轴、资金流向图、轨迹地图、统计图表 |
| 出庭支持 | 证据演示、专家辅助、质证准备 |

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型场景：司法鉴定机构出具鉴定报告、公安侦查取证报告、检察院证据审查、法院电子证据展示、企业合规审计报告。

## 能力边界

1. 仅用于合法授权范围内的取证与报告工作；
2. 不替代鉴定人签署与机构出具，报告最终由有权主体确认；
3. 法规依据随政策更新，使用前需核对现行有效版本。
