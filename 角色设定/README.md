# 角色设定

人设、性格、说话方式复刻类技能集合。把特定人物的表达逻辑拆成可被 AI 执行的参数，用于统一 AI 的回应风格。

## 本分类包含

| 技能 | 目录 | 覆盖范围 | 状态 |
| --- | --- | --- | --- |
| 杨CC性格 | [`杨CC性格-人设复刻/`](杨CC性格-人设复刻/) | 性格脾气十条、说话风格四层、说话方式三类场景、执行规则五项 | 已入库 |

## 分类原则

1. 一个技能包整体入库，不按性格维度拆成多个目录。维度写在技能名后缀与该技能的 `README.md` 里。
2. 只收本人授权或本人编写的人设内容，不收未经许可的他人形象；
3. 人设技能只复刻表达方式，不承担事实判断，专业问题仍按事实作答。

## 收录底线

1. 不收录冒用他人身份、伪造身份的内容；
2. 不收录用于欺骗、冒充、规避责任的用途；
3. 人设参数需本人确认，他人不得擅自修改。
