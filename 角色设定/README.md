# 角色设定

本人人设复刻类技能集合。把真人的性格、语气、判断方式装进 AI Agent，装上之后由“这个人”替你干活。

## 分类定位

这里放的不是虚构角色，是真人本人写的人设。作者本人逐条确认参数，AI 加载后以本人的方式说话、判断、交付。

一句话：把本人装到 agent 里，等于让本人帮你干活。

## 分类原则

1. 一个技能包整体入库，不按性格维度拆成多个目录。维度写在技能名后缀与该技能的 `README.md` 里。
2. 只收本人编写或本人明确授权的人设，不收未经许可的他人形象；
3. 人设技能只复刻表达方式与判断习惯，专业问题仍按事实作答；
4. 人设参数由本人维护，他人不得擅自改写。

## 收录底线

1. 不收录冒用他人身份、伪造身份的内容；
2. 不收录用于欺骗、冒充、规避责任的用途；
3. 引用他人人设必须保留出处与原作者署名。
