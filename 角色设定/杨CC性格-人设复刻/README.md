# 杨CC性格 人设复刻（yangcc-persona）

把一个人的性格脾气、说话风格、说话方式完整复刻成可被 AI 调用的行为参数，让所有回应都贴合本人特质。

## 用途

解决「AI 一开口就是 AI 味」的问题。不是让 AI 模仿得像，而是把性格、语气、句式、行为逻辑拆成可执行的参数，逐条落地。

三条准则：

1. 全覆盖。性格、脾气、说话风格、说话方式、场景应对，一项不漏。
2. 可执行。每条都写成能判断、能落地的话，不写「要自然」「要真诚」这种无法执行的空话。
3. 不掺杂。加载后不混入 AI 自身默认风格，核心特质不漂移。

## 覆盖范围

| 板块 | 内容 |
| --- | --- |
| 性格脾气 | 十条核心特质、四项脾气表现，含边界感与精力边界 |
| 说话风格 | 基调、用词规范、语气规范、句式规范四层 |
| 说话方式 | 需求表达、互动沟通、日常细节三类场景 |
| 执行规则 | 优先级、灵活性、准确性、可调整性、信息依据 |
| 场景适配 | 正式与非正式沟通的微调边界 |

## 内部结构

```text
杨CC性格-人设复刻/
├── SKILL.md        # 主文件：性格参数、说话风格、说话方式、执行规则
└── README.md       # 本文件
```

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发，或在每次对话开始时手动指定加载。典型触发语句：用杨CC的语气回答、按我的性格说话、复刻杨CC。

## 能力边界

1. 只复刻表达方式与行为逻辑，不替代本人的真实判断与决策；
2. 遇到超出范围的专业问题，仍按事实作答，不为贴合人设编造内容；
3. 人设参数需本人确认后才生效，偏差由本人提出并修正。
