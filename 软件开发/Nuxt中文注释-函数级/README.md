# Nuxt 中文注释规范 函数级（nuxt-chinese-comments）

约束 Nuxt 项目中的代码注释：一律中文，且每个函数上方必须有说明。

## 用途

创建或修改 Nuxt 代码时，确保注释完整、语言统一、位置正确，避免出现英文注释、注释缺失、注释与代码脱节。

## 覆盖范围

| 注释类型 | 位置 | 要求 |
| --- | --- | --- |
| 文件头部注释 | 文件首行起 | 说明该文件的职责与主要内容 |
| 函数注释 | 每个函数上方 | 说明用途、参数、返回值 |
| 代码块注释 | 复杂逻辑段前 | 说明该段的意图，不逐行复述 |
| 组件注释 | 组件定义上方 | 说明组件用途与适用场景 |

附带完整 Nuxt 页面示例、检查清单与最佳实践。

## 内部结构

```text
Nuxt中文注释-函数级/
├── SKILL.md        # 四类注释规范、示例、检查清单、最佳实践
└── README.md       # 本文件
```

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型触发语句：创建 Nuxt 页面、修改 Nuxt 组件、补中文注释、注释不规范。

## 能力边界

1. 只管注释，不改逻辑、不改命名、不动样式；
2. 不适用于非 Nuxt 项目，其他框架需另立规范；
3. 不强制为简单赋值语句加注释，避免注释噪音。
