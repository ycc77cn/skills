# Nuxt 极简设计 三要素（nuxt-minimalist-design）

Nuxt 页面与组件的极简主义设计约束：高留白、黑白配色、高对比阴影。

## 用途

创建或修改 Nuxt 页面时，把视觉风格收敛到极简一套，避免花哨渐变、堆叠装饰、配色混乱。

## 覆盖范围

| 方面 | 规范要点 |
| --- | --- |
| 整体风格 | 高留白、低信息密度、黑白为主 |
| 页面结构 | 分区清晰、层级单一、避免多层嵌套 |
| 颜色规范 | 黑白灰三阶为主，强调色只用一种 |
| 布局规范 | 栅格对齐、边距统一、留白比例固定 |
| 组件规范 | 圆角、阴影、边框统一取值 |

另含禁止元素清单、完整页面示例、设计检查清单与常见问题解答。

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型触发语句：创建 Nuxt 页面、改页面样式、要求极简风格、页面太花。

## 能力边界

1. 只管视觉风格，不涉业务逻辑与数据结构；
2. 不适用于需要强视觉冲击的营销页、活动页；
3. 不替代品牌 VI，品牌项目需按品牌规范覆盖本技能。
