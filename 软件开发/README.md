# 软件开发

面向工程实践的技能集合，覆盖代码规范与开发流程两条主线。

## 本分类包含

暂无入库技能。

## 预计收录方向

| 方向 | 内容 |
| --- | --- |
| 代码规范 | 代码本体、文件目录、注释、接口命名、工程规范、安全防护 |
| 开发流程 | 需求沟通到交付的流程约束、备份、验证、收尾 |

## 收录规则

1. 技能目录直接建在本分类下，命名格式「中文名-范围后缀」，例如 `代码编写与重构规范-六维`；
2. 规范类技能支持两种模式：重构既有代码（不改业务逻辑）、生成新代码（直接遵循规范）；
3. 不收录第三方版权技能，不收录内部私有约定。
