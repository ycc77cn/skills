# 软件开发

面向工程实践的技能集合，覆盖代码规范与开发流程两条主线。

## 本分类包含

| 技能 | 目录 | 覆盖范围 | 状态 |
| --- | --- | --- | --- |
| 代码规范化 | [`代码规范化-六维/`](代码规范化-六维/) | 代码本体、文件目录、注释、接口命名、工程规范、安全防护六维；重构与写代码两模式 | 已入库 |
| 开发标准流程 | [`开发标准流程-七步/`](开发标准流程-七步/) | 七步流程约束，含贯穿纪律与完成标准 | 已入库 |
| Nuxt 中文注释 | [`Nuxt中文注释-函数级/`](Nuxt中文注释-函数级/) | 文件头、函数、代码块、组件四类中文注释 | 已入库 |
| Nuxt 极简设计 | [`Nuxt极简设计-三要素/`](Nuxt极简设计-三要素/) | 高留白、黑白配色、高对比阴影三要素 | 已入库 |
| 代码备份 | [`代码备份-ZIP归档/`](代码备份-ZIP归档/) | beifen 目录、ZIP 格式、时间与操作说明命名 | 已入库 |

## 预计收录方向

| 方向 | 内容 |
| --- | --- |
| 代码规范 | 代码本体、文件目录、注释、接口命名、工程规范、安全防护 |
| 开发流程 | 需求沟通到交付的流程约束、备份、验证、收尾 |

## 收录规则

1. 技能目录直接建在本分类下，命名格式「中文名-范围后缀」，例如 `代码规范化-六维`；
2. 规范类技能支持两种模式：重构既有代码（不改业务逻辑）、生成新代码（直接遵循规范）；
3. 不收录第三方版权技能，不收录内部私有约定。
