# 代码备份 ZIP 归档（code-backup）

代码变更前的强制备份规范：固定目录、固定格式、固定命名。

## 用途

任何代码改动之前，先把当前可用状态打包留档，保证改坏了能一步退回。

## 覆盖范围

| 项目 | 规定 |
| --- | --- |
| 备份目录 | 根目录下的 `beifen` |
| 文件格式 | `.zip` |
| 命名格式 | `年-月-日_时-分-秒_操作说明.zip` |
| 命名示例 | `2026-01-29_12-52-15_修改XXX接口参数.zip` |
| 备份内容 | 目录内全部代码 |
| 排除内容 | 依赖库、编译产物、`.pyc`、缓存、日志等非源码文件 |

排除项由执行者按项目类型判断：Node 项目排除 `node_modules` 与构建目录，Python 项目排除 `__pycache__`、`.pyc`。

## 内部结构

```text
代码备份-ZIP归档/
├── SKILL.md        # 备份基础要求全文
└── README.md       # 本文件
```

## 调用方式

由 AI 工具按 `SKILL.md` 的 `description` 自动触发。典型触发语句：备份、改代码前留档、打包当前版本、回滚准备。

## 能力边界

1. 只备份代码，不备份依赖库、编译产物与临时文件；
2. 不负责版本控制，长期版本演进仍用 git；
3. 不自动清理旧备份，保留策略由使用者自行决定。

## 版本

- 依赖：PowerShell `Compress-Archive` 或 7z
- 许可：遵循仓库根目录 MIT
