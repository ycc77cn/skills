# 校验清单

> 本文件是 code-refactor skill 的拆分规则文件，详细定义校验清单。AI 输出前必须逐条过。

---

## 一、业务一致性校验（重构模式）

- [ ] 所有原文件功能模块均保留，无遗漏
- [ ] 核心业务逻辑（运算、判断、循环）未改动
- [ ] 所有原对外接口签名、路径、请求方法保持不变
- [ ] 所有数据库表 / 字段 / SQL 业务条件未改动
- [ ] 所有原有异常捕获分支保留
- [ ] 没有新增业务功能、接口、字段

---

## 二、文件 & 目录校验

- [ ] 零散文件已归类到对应目录
- [ ] 文件命名符合语言标准风格
- [ ] 无用空文件、临时测试文件已删除
- [ ] Import / Require 三段式分组、同组字母序、去重
- [ ] 未使用的 import 已清理
- [ ] 业务逻辑文件 ≤ 500 行，工具函数文件 ≤ 300 行
- [ ] 单一职责：一个文件只做一件事
- [ ] 配置文件按环境分离（dev / prod / test）
- [ ] 敏感文件（.env、密钥）不在 web 根目录
- [ ] 日志文件存放在独立 logs/ 目录

---

## 三、命名规范校验

- [ ] 变量 / 函数 / 方法英文语义化命名
- [ ] 常量全大写下划线
- [ ] 类 / 结构体 / 接口大驼峰
- [ ] HTTP 接口名动词 + 资源
- [ ] HTTP 路径小写 + 横杠
- [ ] 数据库表 / 字段下划线
- [ ] 全项目命名风格统一，无混用
- [ ] 无拼音、无意义缩写、无单字母变量（循环变量除外）
- [ ] 无模糊命名（doWork、handleData、process、tmp）

---

## 四、注释规范校验

- [ ] 每个文件都有头部说明注释
- [ ] 每个类 / 接口 / 函数都有标准文档注释
- [ ] 复杂逻辑有「为什么这么写」的单行注释
- [ ] 打印调试注释已删除
- [ ] 过期废弃注释已删除
- [ ] 重复冗余注释已删除
- [ ] 注释中无敏感信息（密码、Token、身份证号）
- [ ] 中文注释用词规范，无口语化、错别字

---

## 五、格式规范校验

- [ ] 缩进风格统一（2 / 4 空格固定）
- [ ] 无 tab 与空格混用
- [ ] 函数之间空行固定 2 行
- [ ] 逻辑块之间空行固定 1 行
- [ ] 连续多行空行已压缩
- [ ] 文件末尾保留 1 行空行
- [ ] 运算符前后有空格
- [ ] 逗号后有空格
- [ ] 单行不超过 120 字符
- [ ] 魔法数字已提取为常量
- [ ] 临时调试代码已删除

---

## 六、接口规范校验

- [ ] HTTP 请求方法使用正确（GET / POST / PUT / DELETE）
- [ ] HTTP 路径小写 + 横杠
- [ ] 返回体统一为 `{ code, msg, data }` 结构
- [ ] 分页接口返回体含 `list / total / page / page_size`
- [ ] 函数参数超过 3 个已封装为结构体
- [ ] 重复逻辑已抽离为公共方法
- [ ] 接口参数校验注释补齐
- [ ] 所有接口输入参数已校验（类型、长度、范围）
- [ ] 返回体敏感字段已脱敏

---

## 七、安全规范校验

> **安全校验项全部通过才能上线，任何一项不通过必须修复。**

### 7.1 SQL 注入防护校验

- [ ] SQL 查询使用参数化查询，禁止字符串拼接
- [ ] ORM 查询使用预编译语句
- [ ] 禁止动态 SQL 拼接用户输入

### 7.2 XSS 防护校验

- [ ] 用户输入输出已转义过滤
- [ ] Cookie 设置了 HttpOnly 属性
- [ ] 富文本已净化处理

### 7.3 CSRF 防护校验

- [ ] CSRF Token 验证机制已实现
- [ ] Token 长度 ≥ 32位随机字符串
- [ ] Token 存储在 HttpOnly Cookie 中

### 7.4 身份认证校验

- [ ] 密码使用 BCrypt / Argon2 哈希存储
- [ ] Token 设置了过期时间
- [ ] 权限控制已实现（RBAC）

### 7.5 输入验证校验

- [ ] 所有接口输入参数已校验
- [ ] 字段类型、长度、范围已校验
- [ ] 特殊字符已过滤

### 7.6 敏感数据保护校验

- [ ] 日志中无敏感信息（密码、Token、身份证号）
- [ ] API 返回敏感字段已脱敏
- [ ] 数据库敏感字段已加密

### 7.7 接口安全校验

- [ ] 接口设置了限流和频率限制
- [ ] 错误响应不暴露技术细节
- [ ] 敏感接口有二次验证

### 7.8 文件上传安全校验

- [ ] 文件上传有类型白名单和大小限制
- [ ] 文件存储不在 web 根目录
- [ ] 文件访问有鉴权

### 7.9 安全配置校验

- [ ] 禁止硬编码敏感信息（密码、密钥、Token）
- [ ] 调试模式在生产环境已关闭
- [ ] 默认密码已修改
- [ ] HTTPS 已开启

---

## 八、写代码模式校验清单

> 写代码模式生成代码时，必须同步执行以下校验。

### 8.1 目录生成校验

- [ ] 目录结构符合分层标准
- [ ] 文件大小符合限制（业务500行、工具300行）
- [ ] 敏感文件隔离（.env、密钥不在web根目录）

### 8.2 命名生成校验

- [ ] 变量、函数、类命名符合风格规范
- [ ] HTTP接口命名符合REST风格
- [ ] 无拼音、无意义缩写、无模糊命名

### 8.3 注释生成校验

- [ ] 所有文件有头部注释
- [ ] 所有函数有文档注释
- [ ] 注释中无敏感信息

### 8.4 安全生成校验

- [ ] SQL查询使用参数化查询
- [ ] 密码使用BCrypt/Argon2哈希
- [ ] Token设置过期时间
- [ ] Cookie设置HttpOnly
- [ ] 所有接口有输入验证
- [ ] 日志禁止敏感信息
- [ ] API返回敏感字段脱敏
- [ ] 错误响应隐藏技术细节
- [ ] 文件上传有白名单
- [ ] 禁止硬编码敏感信息
