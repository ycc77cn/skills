# 自动备份 永不删除（code-backup）

代码修改后自动触发的备份执行器。规则版规定"怎么备份"，本技能负责"自动做"。

## 技能定位

两个备份技能配合使用：

| 技能 | 角色 | 管什么 |
| --- | --- | --- |
| 代码备份-ZIP归档 | 规则版 | 备份目录、命名格式、排除项、执行时机（改码前必须备份） |
| **自动备份-永不删除** | 执行版 | 改码后自动执行、内容总结命名、永不删除备份 |

规则版写的是纪律（必须备份），本技能写的是自动执行。一个是要求，一个是执行器。

## 触发场景

- 修改了任何代码文件的内容
- 添加了新的代码文件
- 删除了现有代码文件
- 对代码结构进行了任何更改

## 规则细则

| 项 | 规则 |
| --- | --- |
| 备份目录 | 当前项目根目录下的 `beifen/`，不存在则自动创建 |
| 文件命名 | `YYYY-MM-DD_HH-mm-ss_内容总结.zip`，内容总结 20 字以内 |
| 备份内容 | 整个项目目录的所有文件（同规则版的排除项一致） |
| 保留策略 | **永不删除**，只有用户可以手动删除 |
| 排除项 | `node_modules`、编译产物（pyc）、依赖库等非代码文件 |
| 覆盖保护 | 永不覆盖任何现有备份文件 |
| 执行时机 | 每次代码变更后**立即自动执行** |

## 执行步骤

1. 检查 `beifen` 目录，不存在则创建
2. 生成当前时间戳
3. 基于最近代码变更生成内容总结
4. 组合命名：`时间戳_内容总结.zip`
5. 将项目目录压缩到备份文件
6. 保存到 `beifen/` 并输出成功信息

## 与规则版的区别

| 维度 | 代码备份-ZIP归档（规则版） | 自动备份-永不删除（执行版） |
| --- | --- | --- |
| 触发方式 | 手动，改码前必须执行 | 自动，改码后立即执行 |
| 时机 | 改码**前** | 改码**后** |
| 命名 | `年-月-日_时-分-秒_操作说明` | 时间戳 + 20 字内容总结 |
| 核心纪律 | 改码前必须备份 | 永不删除备份 |
| 体量 | 15 行简短规则 | 51 行完整执行逻辑 |

## 使用示例

| 变更 | 自动生成的备份文件名 |
| --- | --- |
| 修改了功能卡片布局 | `2026-01-29_19-30-45_修改了功能卡片布局.zip` |
| 添加了新的服务区域 | `2026-01-29_20-15-30_添加了新的服务区域.zip` |
| 更新了导航栏样式 | `2026-01-29_21-05-10_更新了导航栏样式.zip` |
